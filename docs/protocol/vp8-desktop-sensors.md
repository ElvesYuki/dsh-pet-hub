# 桌面宠物设备传感器查询

页面在原电池 USB 会话中提交 `SENSORS1` 和 `BATTERY1`，使用同一请求 ID。约每 5 秒一次，退出页面取消定时器和在途工作。现有身份复核、串口互斥、归属冲突与后台更新门限保留。两条回包独立，老固件仍显示电池。传感器显示触摸状态、最近触点、含重力的三轴加速度和三轴角速度。过期读数沿用已有的 7.5 秒标旧和 15 秒隐藏规则。

宿主验收覆盖分片、错误请求 ID、坐标和量程边界、IMU 不可用、旧固件、电池独立错误及离页取消。现场验收使用现有 DSH `0.2.2-rc.3`，对照 1.75C-EN 的固件、触摸取样、平放和倾斜读数，以及离开页面后的串口释放。原合并主包 `0.0.4` 用于回退。

现场通过已签名 DSH `0.2.2-rc.3` 的原 CLI 安装 `0.0.5`。板上 `0.1.10`，用户实际轻点并倾斜，确认挥手。页面读到最近坐标 `(261, 238)` 和变化后的三轴加速度。离页后 11 秒内 21 次检查均未见串口占用。
