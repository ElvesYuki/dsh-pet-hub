# G0-R3 管理端 wire 提案与双语言宿主验证

## 交付与决定

新增[闭合契约表](../../packages/core/round-pet-wire-contract.json)、[纯core codec/账本](../../packages/core/round-pet-wire.mjs)、[原创C++17宿主oracle](../../native/round-pet-wire-check.cpp)、[固定向量](../protocol/vectors/round-pet-wire-v1.json)、[24专项](../../tests/round-pet-g0-r3.test.mjs)和[隔离监督入口](../../scripts/verify-round-pet-g0-r3.mjs)。未修改旧A4/A3/lease/session/装配的运行入口，不改候选缺省或设备通道开关。

完整管理端选择以[wire/1提案](../protocol/round-pet-wire-v1.md)及闭合表为准：

- 独立round-pet-native360-wire/1，protocol=hub-device/1，固定/hub-device/v1相对路径；媒体profile/N、原生360/24fps/241帧、V2 4+1与0/4保护保持。旧A4及旧v5严格区分，不改名直连。
- 完整schema2能力/hello选择、会话(P,M,N)、request_seq与完整context；capabilities2/control1/lease1/playback2/display2/storage2/inventory1/touch1/cancel1/error1显式协商。新hello仅表示完成，尚未装配进认证session owner。
- playback接纳ready/deferred_local、首帧与display维护分开；storage2区别saved/root_commit、already_available/inventory_reference、deferred、failed、cancelled_pre_gate、outcome_unknown；cancel独立结果不代保存确认。本地触摸只观察，binding.revoke回执仅fenced_local、不冒充持久解绑。
- 22个固定错误码的HTTP/恢复表，所有automatic_retry=false；不泄露cause、不重放未知副作用。request/流序列均uint64字符串，闭合字段与canonical UTF8严格校验。
- body4096B/头8192B/Range32768B/写块4096B保持；8动作页含最大身份与序列的向量3075B。数字/路径helper不是HTTP parser、许可或资源上界。
- 纯账本最多1个HTTP、1个未确认control及7流高水位；错误dispatch/target/operation/包/epoch/旧会话不消耗pending，close清理并拒绝晚结果。认证、期限、资产白名单、命令/operation完整生命周期、A3投影及A8durable发布仍由后续adapter/既有owner负责。

## 实测

环境Node24.14.1/npm11.11.0；Apple clang21.0.0，C++17以-std=c++17 -Wall -Wextra -Werror编译。仅使用已有工具与stdlib，无第三方新增依赖或上游实现复制。C++产物只写自有临时目录，不构建固件。

专项分组：R3-01–09固定合同身份、正反字节、配置故障与报文拒绝区分、消息覆盖、容量、旧profile拒绝、路径/Range及错误恢复；R3-10–17单在途/单pending、接纳与下载许可、原子拒绝、保存/取消/租约/查询与本地fence关联；R3-18–24非关联事件流新鲜度、旧context/包/HTTP echo拒绝、close与晚结果、无法解析error空关联、页顺序、uint64极值及快照隔离。

固定数据只有虚构身份/descriptor及摘要占位，不含真实动画、凭据或本机运行响应；固定N仅标媒体namespace，不提供素材批准。C++独立实现解析/语义校验，契约表是共同输入；会话账本状态测试只在Node执行，**没有C++ TLS、Flash或状态owner**。首次专项检查暴露的C++坏配置出口和旧lease子对象测试序列化问题已修正，未放宽字段、限额或TTL。

R3监督项不创建socket、不读取固件/真实素材/运行配置；完整回归含既有私有UDS/loopback TLS模拟，不启动生产listener或连接实体设备。未安装插件、烧录、修改固件/pet/bridge/DSH配置、提交或推送。并行400与用户已有修改保留。

## 未覆盖、下一入口与回退

1. **共同G0未关闭**：需固件任务独立审阅同一合同SHA/字节向量及字段可行性，管理端宿主C++不代固件签核。外部事实仍为G0-R1只读快照，本轮未重新核设备驻留或恢复A/B现场。
2. 下一先Spec/Diff做**默认关闭的宿主adapter**，只用临时loopback、原创素材与PKI，复用session/guard/A2/A3/R2/A8，验证选择/包绑定同socket挑战、schema2投影、错误/pending清理、取消/命中/迟到/unknown与恢复；不得把旧profile全局放宽或跳过动态授权、期限及durable顺序。新合同变更须显式修订表/向量和重验。
3. 真实360素材身份复核不等于独立许可/用途批准；无新approval或真实A2全库导入。原始形象声明、用途/署名传播范围、独立offline-validation批准继续待补，不从哈希或本轮向量自封批准。
4. 正式UI/设备触摸、RTOS gate/刷新/持久提交、实际协议承载尚未装配；G1完整维护、G2 TLS峰值/可信时间/凭据持久化/撤销与取消清理上界未验。loopback/本轮字节长度不是最坏物理时延，不延TTL放行；设备窗口独立授权。

回退仅撤回本轮独立codec/表/oracle/向量/测试，删除自己创建的临时产物；无运行配置、持久格式、namespace或lease期限迁移。旧A1–A10/R2继续有效，不停止或恢复外部服务。C01–C12交接、基线表与当前摘要已同步，旧wire未定义记录已[按主题归档](../context/history/round-pet-g0-r3-evolution.md)，只替代该缺口，不抹去来源/许可/资源限制或并行400成果。
