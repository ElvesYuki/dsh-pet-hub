# 桌面宠物设备合并页实装报告

2026-11-17。[Spec](../context/plans/vp8-desktop-device-page-spec.md) · [Diff](../context/plans/vp8-desktop-device-page-diff.md)。

主 Hub 的设置项保留 `dsh-pet-hub-settings`，新名称为「桌面宠物设备」。配套登记包使用同一包名及原宿主配置，提供原登记后端和一个零设置槽的替换客户端。页面把 1.75C-EN 的查询信息、本地绑定和本次设备核对放在一张 USB 卡中。查询成功即使固件和槽位未变化，也显示「已读取设备信息」。普通客户端、Web 和历史候选构建继续使用原入口。

「绑定设备」「验证绑定」「核对绑定」分别沿用原绑定命令和持久证明。「查询设备」走原免码只读路由，在绑定后端不可用或固件能力不足时仍可用。两包在同一宿主进程内共享 USB 排他，锁定持续到实际 TTY 关闭。已有 POSIX 排他继续保护其他进程。宿主提供目标关系和忙碌状态，页面据此决定如何展示查询结果。

| `dsh-pet-hub-boot-review-0.0.2.tgz` | 登记后端及零槽替换客户端 | `4fbed8a59150e9067ad3d603e91c837904b2099f47ab0c69074d9d0a1fb479b4` |

复建使用 `npm run build`、`node scripts/build-dsh022.mjs --host-version 0.2.2-rc.3 --combined` 和 `node scripts/build-vp8-boot-rc3.mjs --backend-only`，再对两条输出目录执行本地 `npm pack`。

现场在已打开的 DSH 完成主包更换，保留已启用的登记包 `0.0.2`。以下命令留作操作记录，`$hub` 指向当时使用的主包本地 tarball。

```sh
dsh plugin --profile desktop add "$hub"
```

回退时用相同命令恢复主包 `0.0.1` 的本地文件，继续使用已实装登记包 `0.0.2`。该历史主包仍会在归属未确认时隐藏版本与槽位。现场私有 Keychain 和设备配置的原址见[实装报告](2026-11-17-vp8-usb-desktop-hotload.md)。

## 已打开 renderer 的升级修正

现场报告主包 0.0.1 已显示「桌面宠物设备」。登记包 0.0.1 完全移除客户端声明后，当前 renderer 中仍保留此前的「设备登记候选」，关闭并重开设置仍可见。登记包 0.0.2 恢复显式客户端声明，沿用旧模块 ID `dsh-pet-hub-boot-review` 与旧客户端名 `pet-hub-boot-review-client`，以空实现触发同身份替换。它不导入 React、调用 slots 或发送请求。

登记包 0.0.1 → 0.0.2 比对通过。除清单及新增客户端外，177 个打包文件逐字节一致。真实 tarball 的同 renderer 夹具从主包加旧登记客户端的双入口切换到新登记客户端，验证旧槽解除且主槽仍在。现场随后确认当前 DSH 热替换为单入口，合并页可从设备重新核对持久绑定。

## 显示已成功的独立查询

主包 0.0.1 阶段，独立免码查询读到 `0.1.5-usb-pair-test`／`ota_1`，合并页仍显示「尚未查询」。两侧私有设置的 USB 身份和 callout 实测相同，宿主投影中的目标关系仍未确认。

主包 0.0.2 直接使用既有 STATUS2 投影。查询成功且固件版本、槽位有效时，`sameUsbTarget` 为 null 或缺失会显示独立的「USB 查询结果」及「与绑定目标的关系待核对」。只有 true 允许结果归入绑定卡。false 仍提示 USB 冲突并隐藏固件和槽位。失败或数据无效不生成结果区域。主包 0.0.1 与 0.0.2 的 tarball 只有客户端、合并页源码与清单字节变化。

## 宿主验收

真实打包测试解开配套 tarball 并执行客户端，验证只有一个旧 ID 的新命名设置槽。覆盖绑定状态、能力缺失、并发按钮、查询成功反馈和四类归属输入（true、false、null、缺字段），以及失败、无效槽位。查询路由保持精确命令、旧实例拒绝和原免码门禁。分别载入两份本地包的宿主模块测试共同 USB 排他和关闭失败保持隔离。普通 Desktop 客户端摘要保持原审核值。

锁定 Node `24.14.1`、npm `11.11.0`。主包 0.0.2 的构建、`npm run check`、专项打包测试及全量 `npm test` 通过，共 2,073 项，无跳过。登记包 0.0.2 的已部署产物摘要保持原值。
