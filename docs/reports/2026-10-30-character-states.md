# 四态桌面候选实现与验证

2026-10-30。用户授权实施；先写[Spec/Diff](../context/plans/character-states-spec.md)。本次仅制作预览，不接真实pet状态、设备或固件，不修改运行服务。

## 实现结果

| 状态 | 当前表现 |
| --- | --- |
| idle 待机 | 自然呼吸、独立眨眼、11发束动态 |
| thinking 思考 | 轻歪头、挑眉、半闭眼，保留眨眼闭合过程 |
| working 工作 | 减弱头部晃动，现有双臂小幅交替；不是新增打字或挥手姿态 |
| success 完成 | 约1.4秒单次笑眼/微笑及轻晃，结束返回最新基础态 |

新增纯逻辑 `scripts/character-states.mjs`，无DOM/DSH依赖；桌面预览通过显式开关启用，旧自然动作/说话预览默认行为保留。三基础态目标权重用约0.45秒平滑过渡，中途改目标从当前权重接续；自然运动按120Hz固定步长积分，不清空弹簧位置/速度。0.45秒是目标权重过渡时间，不是所有物理通道已回稳的保证。

工作双臂目标交替幅度约±2.2度、周期1.6秒；四态模式下手臂限幅3度、限速12度/秒。复用现有整臂图，只适合当前小幅活动；大幅举手/挥手需额外姿态和关节遮挡补画。工作与待机静态形象接近，主要依靠运动区分，尚未通过用户视觉辨识度验收。

摸头是独立反馈，期间基础态继续切换，结束回到最新基础态。完成反馈不覆盖基础态，活跃期间新完成请求拒绝且不排队，最近32个已接受ID有界去重；这是离线制作控制，不是持久消息交付协议。眨眼时钟不因切换重置；说话通道最后组合并独占嘴部，触摸和完成表情不抢说话嘴型。

360画布与固定原点、身体根矩阵恒等、原人物注册大小保持；原46个PET4动作没有变更。21个绘制层SHA、表情素材manifest SHA和标准底稿SHA与前一说话预览一致，19张制作贴图全部复用，没有新增美术生成。代码MIT，素材仍沿用既有非商业改编与署名边界，见[来源许可](../../THIRD_PARTY.md)。

## 验证证据与范围

- `npm run check` 通过；`npm test` 194/194通过，含新增6项状态测试。测试覆盖中途过渡接续、姿态/速度连续、最新基础态恢复、完成去重/拒绝、有界历史、眨眼与说话组合、固定步长可重放、非法输入和关闭开关保护。
- 浏览器实际按钮验证：待机→工作→摸头→思考；触摸结束时基础态为思考，未回到旧工作态；完成按钮正常出现笑眼，活跃时重复完成返回busy，结束恢复思考。
- 10段场景、每段12秒按24Hz采样289次，共2890次。涵盖三基础态、单次完成、触摸期间切换、快速切换、完成期间切换、重复完成、无音频说话组合、停止回稳。逐场景低透明内部覆盖候选和越安全圆候选均为0。
- 内部覆盖使用原静态alpha≥240、向内侵蚀4像素的31423像素掩膜，运动合成alpha<200记候选；安全圆中心(180,180)、半径166.5。扫描只是这些场景下的几何/覆盖筛查，不证明解剖正确、所有可能输入安全或视觉自然。
- 动态可见包围盒并集：待机[70,49,282,315]、思考[70,49,281,315]、工作[69,49,282,315]，其余场景通常[70,49,282,315]；边缘随局部运动变化，不代表重新缩放或居中。停止场景末尾通道最大绝对位移约3.18e-18，已回稳。
