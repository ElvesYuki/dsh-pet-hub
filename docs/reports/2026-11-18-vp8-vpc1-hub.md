# VP8 VPC1 Hub 离线验证

2026-11-18。已实现严格 VPC1 编解码、定长分帧、单设备会话与可过期最新目标。测试传输只使用本机 loopback。板端 `0.1.24` 留驻，`0.1.21` 是回退。当前板端 VPC1 证据为固件控制核心宿主验证，Hub 证据为模拟显示。 [Spec 与 Diff](../context/plans/vp8-vpc1-hub.md) · [协议差异与无线认证](../protocol/vp8-vpc1-hub.md)

## 证据与复现

- `packages/core/vp8-vpc1.mjs` 固定向量、23 个分段位置、粘包、非法字段和不完整 EOF。纯模型用手动时钟覆盖回执顺序、重复、过期、旧连接、显示序号回退、待回执上限、心跳失效及只以剩余 TTL 重放最新目标。
- 真实 loopback 覆盖半帧 EOF。Node Hub 直接与固件仓库的 C++ `vp8_control_loopback.cpp` 和 `main/vp8_control.cpp` 交换 TCP 字节。夹具以 11 B 缓冲读入，先保持本地繁忙，验证动作 4 被动作 57 覆盖，随后 Pong、Presented 和 Missing。显示序号 77 来自夹具模拟，宿主关闭后对端退出。
- 同一命令先编译并运行固件 C++ 原 `vp8_control_test.cpp`。两个 C++ 产物启用 ASan／UBSan，在临时目录编译与清理。只读引用固件仓库文件，编译由管理端测试发起。

在 Hub 根目录运行，`firmware_root` 指向本机的固件仓库。

```sh
ROUND_PET_VPC1_PEER_ROOT="$firmware_root" node --test tests/vp8-vpc1.test.mjs
```

8 项专项通过，包括实际固件对拍。`npm run check` 与含构建的 `npm test` 共 2,088 项通过，无失败或跳过，其中包含同一工作区的 USB 传感器测试。
