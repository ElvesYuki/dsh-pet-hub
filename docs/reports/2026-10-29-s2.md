# S2显式模拟服务、IPC与界面验收

2026-10-29。先写[Spec](../context/plans/s2-spec.md)/[Diff](../context/plans/s2-diff.md)，再装配。无子智能体，无真实设备/固件/pet/bridge调用，未修改任何DSH profile，未安装/启用插件，未提交推送。

## 实现与运行边界

- CLI新增显式`--device-mode simulation`，默认disabled；simulation仅与source-mode disabled共用，禁止同时装配真实HTTP/page来源。
- startOrAttach只在socket所有权取得后调用注入的simulationFactory。设备模式加入服务指纹，不同模式不能附着或通过IPC切换。
- packages/simulator/session.mjs组装S1 core注册表、actor、调度器与虚拟时钟。两设备sim_A/sim_B、8个微型合成素材，默认注册/控制/提出空闲目标；只有用户显式推进时间才产生校验/首帧/心跳/续租事件。GET status无调度副作用。
- 模拟下载300ms后verified、400ms后首帧事件，都是合成时序，不是性能承诺。模拟断连立即展示offline/无控制权并保留最后观测，重连新session/lease并回auto，不盲重播旧手动意图。
- service status增加deviceMode、synthetic、simulation(revision/time_ms)、设备白名单摘要。deviceTransport始终false；默认模式仍devices=[]。
- IPC POST `/v1/simulation/intent`：按设备用户意图CAS。`/v1/simulation/control`：advance/offline/reconnect/source白名单，每种操作仅收对应字段；global revision CAS。服务实例、client/request ID、幂等、旧实例拒绝均在服务端执行。
- 单次advance为1–30000ms；模拟会话最多128个不同写请求，耗尽拒绝且状态不变，需要重启临时服务。模拟数据/时钟/去重不落盘，用户displayName配置仍沿用旧CAS持久化。
- host白名单代理继续做JSON/同源头检查、限制请求体；转发业务400/409，内部路径错误归为503，不泄露token/本机路径。页面仅获得非秘密serviceInstanceId作代数校验。
- UI持续标识“模拟模式 · 非实物”，显示虚拟时间、来源、两设备的绑定/连接/控制、目标/已观测动作、阶段和手动/自动模式。按钮只在simulation出现。动作请求受理不冒充playing，离线时操作禁用；CAS冲突提示刷新后重试，无隐式重发。
- 默认候选包继续排除simulator，不打包测试认证proof；只有仓库CLI显式动态导入。真实transport、BLE及凭据存储未实现。

`npm run check`、`npm test`（含build）、`node --check dist/client.js`及差异检查通过；原49项+新增11项=60项，0跳过。`npm run test:sim`仍覆盖S1的30+4模型案例。

| S2用例 | 已验证行为 |
| --- | --- |

| 单实例装配 | 第二客户端附着不再构造actor；纯status读取不推进时间 |
| 状态链与双设备 | accepted→verified→playing流经UDS，A工作/B待机分别确认；续租跨原截止点仍有效 |

## 浏览器真实组件验证

使用独立临时UDS hub+动态loopback HTTP模拟host，不启动DSH。加载构建后的dist/client.js，通过简化ModuleLoader/slots测试壳挂载**真实React 18.3.1**组件。React/ReactDOM只从本机安装的DSH只读提取到忽略的.cache/s2临时文件，不联网下载、不复制到Git/候选包；其代码继续遵守各自MIT许可。

- 初始显示醒目模拟标签、虚拟时间0、两设备accepted；配对按钮禁用。
- 点击A工作：A目标11、actual未知，B仍目标0。推进1秒后A actual11、B actual0，均有模拟首帧回执。
- 点击A断连：offline/无控制权，4个设备意图按钮禁用，显示最后观测说明；B不受影响。
- 浏览器测试页另一请求先修改模拟revision，再点击旧快照推进：显示“状态已变化，请检查最新状态后重新操作。”，没有盲重发。该刻意409是预期控制台资源错误，非组件异常。
- 调用测试壳卸载组件，等待清理后两段观察窗口内新status轮询数为0，支持重挂载。
- 截图.cache/s2/ui.png已检查，当前宽度无横向溢出。未做多主题/移动屏幕完整视觉回归。

这些是浏览器真实组件+真实IPC集成，**不是重新安装DSH后的设置槽生命周期验收**；DSH宿主基础契约沿用前轮独立profile证据。本轮未写现有desktop。

## 复现和回退

离线模型：`npm run test:sim`。完整回归：`npm test`。手动仅启动模拟UDS服务：

```sh
trial_dir=$(mktemp -d /tmp/pethub-s2.XXXXXX)
node apps/service/main.mjs --runtime-dir "$trial_dir" --device-mode simulation
```

浏览器交互：`npm run preview:simulation`。准备脚本只接受本机DSH 0.2.1-rc.3的已核对前端布局，变更时明确失败；它生成临时React种子，再创建自己的新runtime和动态loopback端口，不安装插件或更改DSH。此工具仅本地测试壳，不是独立应用发行形式。

本次临时预览已停止，host路由已注销，hub正常关闭并删除其临时runtime。回退只需关闭本试验前台进程；默认服务行为不变。不要为了开启模拟去修改现有desktop或bridge。
