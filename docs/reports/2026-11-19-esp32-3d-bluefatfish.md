# 木子恶魔版大肥鱼 · ESP32 3D 素材评估

2026-11-19。以现有插件待机画面为对照，木子恶魔版保留了 Q 版头身比例、蓝色长发、发箍、蓝白女仆装和鲸鱼围裙。眼睛高光、发箍褶边和裙摆有可见差别。鲸尾从正面不显眼，转至侧后方可看到完整实体。它适合作为独立 3D 路线的形象参考，原网格和贴图规模远超首轮板端原型的目标。配布网页和文件内的修改许可存在冲突，板端减面需先核对作者意愿。 [评估计划](../context/plans/esp32-3d-character-evaluation.md) · [原配布](https://www.aplaybox.com/details/model/ayXkRzVflmnd)

本机对照入口为 `.cache/esp32-3d-bluefatfish-review-v1/index.html`。左侧是当前 400×400 链路的本地动作 0 VP8 样本首帧，原像素居中放入 466×466，偏移 `(33,33)`，源样本 SHA-256 为 `5fbd94b1bd66102e64e90a780e2ba1bc804f26cdd298f88d7d605bdb1b1c8f87`。右侧由同尺寸正交相机渲染原模型静态姿势，保持同一人物高度和相近中心。模型双臂外展是原文件姿势。浏览器对照页可拖动或按按钮切换 12 个预渲染视角，静态页无联网依赖。

以 RGB 任一通道 ≥28 判定可见像素，左侧正面包围框为 `x=121–333, y=102–367`，右侧为 `x=125–328, y=102–367`。正面高度均为 266 像素，参考宽 213、模型宽 204，横向中心差 0.5 像素。12 个采样角度在同一圆屏遮罩下均无可见像素越界。这个几何检查覆盖所测静态姿势，动作和任意连续角度需另测。

面数主要集中在头发 18,013、服装 12,008、头部 10,202，合计占约 88%。领带笔配件占 1,344 面，贴图 PNG 约 7.83 MB。只把身体、衣服、头发和脸的四张 2048² 主贴图按 RGB565 整图解码就要 32 MiB，已经超过板上的 8 MiB PSRAM。原文件体积和磁盘压缩率用于资产管理，运行应另外计算解码后的纹理、颜色和深度缓冲以及蒙皮工作集。浏览器也在正面提交了约 9.13 万个渲染三角面，含 MToon 等额外绘制路径。板端应按实际渲染器重新量化。 [微雪板卡参数](https://www.waveshare.com/esp32-s3-touch-amoled-1.75c.htm) · [同板 a3d 基准](https://github.com/0015/a3d#on-the-panel-at-the-panels-own-resolution-animated)

如果模型作者确认可制作 ESP32 派生版，首轮按相同人物大小评估 500–1000 三角面档位。重点保留刘海、发箍和鲸尾轮廓。用一张 256² 或 512² 的合并贴图承载服装纹样，给眼睛与嘴型预留足够面积。暂以少量关节做头、手臂和尾巴，用开始、结束帧或贴图切换表达眨眼和嘴型。原文件动画片段为空，待机和挥手要另外制作或从有独立许可的动作源获得。帧率、P95 帧耗时、触摸到可见反应和 Wi-Fi 并发资源需在独立固件原型实测。

## 许可和复现证据

模之屋作者页列出允许修改、允许用于视频之外的用途、禁止商用和二次配布、要求完整署名。公开桌面插件说明其副本获得的是随该插件分发的授权。此次核对的同一副本内部还写有 `modification=prohibited`、`avatarPermission=onlyAuthor` 和 `allowRedistribution=false`。应以作者对具体文件和用途的说明解决歧义。本次仅解析并渲染未改动的原模型数据。 [作者配布](https://www.aplaybox.com/details/model/ayXkRzVflmnd) · [插件模型说明](https://github.com/drliuhuan/dsh-plugin-vrmpet3d/blob/462bda9bcdcd4d0d14a4c33ab675bffbfadbcffc/assets/models/README.md) · [VRM 许可字段含义](https://vrm.dev/en/licenses/1.0/)
