## 日常换装

用户授权后已换装同名 Hub。先备份原包与 profile，再用 DSH CLI 离线预演和安装。通过原窗口插件列表刷新后核对新版设置页和既有绑定，页面读回固件 `0.1.32`。原 profile 配置保持一致，USB STATUS3 继续启用。安装后的客户端与插件清单逐字节匹配界面包。后续已验证 Hub 包同样按此方式直接替换。[规则](../../AGENTS.md)

界面包继续显示 `0.0.8`。以插件详情的包来源 `dsh-pet-hub-0.0.8-device-layout.tgz` 区分同版本候选，SHA-256 为 `13994d559ae04cba990547485dac5dfd1bfc8a2e3ee9ac6fb99daf27bc0cba17`。需回退时用 DSH CLI 离线安装上一份 `dsh-pet-hub-0.0.8-status-v2-candidate.tgz`，刷新同一窗口并核对绑定和读数。私有 profile 备份留作配置恢复。
