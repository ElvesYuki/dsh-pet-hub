# S1离线模型验收

日期：2026-10-29。实施前已写[Spec](../context/plans/s1-implementation-spec.md)/[Diff](../context/plans/s1-implementation-diff.md)。无子智能体，无真实DSH/设备/bridge连接，未改固件、pet、桥接配置，未提交推送。

## 交付和复现

- packages/core/protocol.mjs：有界字段、uint64/BigInt、能力和素材匹配、语义相等比较。
- registry.mjs：可信边界注入、绑定注册、认证session、心跳、独立desired/actual/首帧计时、冻结/撤销、配置CAS和白名单摘要。
- device.mjs：设备端参考actor，持久epoch提交、活跃lease排他、幂等命令、四槽缓存、校验/首帧事件、重启清瞬态及撤销模型。
- scheduler.mjs：来源宽限、手动/自动/触摸优先级、跨客户端意图CAS/去重和显式legacy单槽模型。
- packages/simulator：虚拟单调时钟、可控延迟/丢弃/复制/倒序队列、带失败注入的内存持久层、不可序列化proof fixture。ID为确定性计数器，不用真实随机源/凭据或墙钟，因此重复运行可复现。
- test fixture使用8个微型合成素材，实际计算SHA-256，检查自定义SIM1头/尺寸/fps/偏移标志。它们不是PET4，也不是鲸鱼娘46动作，不能代替真实格式/素材验收。

运行`npm run test:sim`只执行离线模型，不创建socket。脚本把逐项操作名/合成目标、拒绝码、时间推进、故障投递及最终状态写入忽略目录.cache/s1/results.json，完整TAP另存results.tap。`npm test`包含已有P1临时IPC/进程回归，不连接运行中的服务；本轮未启动DSH profile。

## 实现中修正的边界

- 续租改变本地expiry不能被当作新命令身份，否则重试会重置首帧计时；比较控制身份时排除expiry，回执仍校验当前lease。
- 初始来源必须unavailable，不能凭默认null伪装已经连接；已连接null才是合法空闲。
- 幂等比较采用属性顺序无关的语义比较，旧session不能读取已撤销operation回执。
- 注册表/发现候选/会话/操作/命令/意图/触摸去重集合设有限上限，耗尽返回capacity_exceeded，不静默丢去重记录。
- build排除packages/simulator，防止将认证fixture装入DSH候选；core参考模型不连接runtime，当前deviceTransport仍为false。

## 尚未覆盖

1. 完整hub-device/1 wire信封编解码、transport/握手、密码学身份证明、TLS、撤销后可信回执恢复、安全存储。
2. 本模型grant中的expires_at是**共享虚拟时钟的本地元数据**，不是可直接上网传输的真实时钟值；承载落地必须以lease_ms在双方各自单调时钟换算，不能复制模拟器的共同时间假设。
3. 真正PET4/LZ4解码、46动作清单完整性、面板首帧、NVS掉电/寿命、PSRAM峰值、24FPS、实体断网/断电、BLE/mDNS及USB恢复。
4. 指数退避/抖动及真实连接并发仍待transport层；S1无真实定时器/重连loop。
5. 未装配simulation运行模式、设备IPC路由、设备管理UI、实际多进程设备命令；这是下一S2范围，SIM-28/30不能冒充该层通过。
