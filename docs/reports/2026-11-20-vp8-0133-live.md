# 0.1.33 与 Hub 真机联调

2026-11-20。独立 Hub 进程使用已封包的 rc.5 候选，复用已登记圆屏的 USB Fence、原 Keychain 与设备公钥。圆屏 `0.1.33`／`ota_1` 经真实 USB 与 TCP 读回，`0.1.32`／`ota_0` 由板端保留。现场验收和日常换装共用以下判定。[验收 Spec 与 Diff](../context/plans/vp8-0133-live-acceptance.md)

| 验收项 | 实测结果 |
| --- | --- |
| USB 首条和周期 | 关闭设置页场景中的隔离进程自动收到 Status v2，连续两间隔 3016、2998 ms。 |
| 配网串口交接 | USB 周期订阅在已有配网流程读取 DESKNET2 INFO 前释放。匹配已登记设备，返回已配置且在线。前台任务释放后恢复订阅。未写入配网。 |
| 升级前串口交接 | 现有升级共用 STATUS3 复核读取 `0.1.33`／`ota_1`，空闲且无待重启。前台读前退订并释放，读后恢复。保留双方已约定的只读范围，未开始 OTA 写入或重启。 |
| TCP 失联回退 | 真机通过 VPL1 mode 3 认证 TCP，上报间隔实测 3041、3007 ms。仅暂停本机候选 socket 的入站读取。距最后有效状态约 6003 ms 清除 TCP 投影，6257 ms 真实 USB 首条接替，9001 ms 旧 socket 关闭。此项覆盖受控链路失联，AP 物理断网另计。 |
| TCP 重连停 USB | 板端重拨，新的认证会话恢复。连续三次新状态期间，USB 无新订阅打开或回执。 |
| 实体拔插与纯电池 TCP | 专项复验确认 USB 设备节点确实消失，用户确认动画继续。原认证 TCP 会话收到至少两条 `usbPower=false` 新状态。插回原接口后同一 TCP 会话恢复 USB 供电标志，经新附着只收到一条 USB 状态，随后退订并释放描述符。 |

全量回归 2128 通过、0 失败、1 项独立 Keychain 专项跳过。本轮真机认证使用原 Keychain。隔离验证结束已收到 DISARM，关闭测试监听并释放串口。

数值证据留在本机忽略的 `.cache/vp8-0133-live.huhqJV/`。`live-controlled.log` 记录失联与恢复，`live-physical.log` 记录实体拔插和收尾。两轮早期拔线窗口超时，日志保留对应过程。原始 USB/TCP 载荷、身份和配置不写入报告。

## 日常换装与回退

同一日常 `desktop` 已换装 `dsh-pet-hub-0.0.8-active-status-candidate.tgz`，启用主动状态和已验证私网端点。先用复制 profile 离线预演并核对实际 rc.5 Electron 配置 schema，再原位换包。原窗口刷新后，插件详情显示新包来源，设备页显示「TCP 实时状态」、`0.1.33`／`ota_1` 和设备已核对的原绑定。现场观察到一个监听和一个已建立的设备 TCP 连接，TCP 接管后 USB 描述符空闲。`dsh-pet` 清单逐字节与备份一致。

旧布局包和旧 profile 私有副本位于本次证据目录的 `rollback/`，已核对清单、配置及客户端。需要回退时把 Hub 恢复为备份的 `dsh-pet-hub-0.0.8-device-layout.tgz` 与原 Cordis patch，再刷新原窗口确认 USB STATUS3 和原绑定。此路径适用留驻 `0.1.33` 的显式 STATUS3。如需固件回退，`0.1.32` 完整保留在 `ota_0`。实际 AP 物理断网和真正 OTA 写入本轮未执行。
