# VP8 设置页 TCP 状态与 USB 回退

2026-11-19 · 管理端候选

[Spec](../context/plans/vp8-desktop-status-spec.md) · [Diff](../context/plans/vp8-desktop-status-diff.md)

## 行为

| 条件 | 页面与宿主 |
| --- | --- |
| 当前认证连接上收到匹配、有效的 TCP 状态 | 展示固件版本、启动槽和已上报的电池／传感器。宿主停掉并取消自动 USB 读，页面也停计时器、取消在途请求并清掉 USB 旧读数。 |
| TCP 断开、被撤销或已有 6 秒无有效状态，且登记 USB 存在 | 设置页请求 USB 回退，首轮在同一个已核对身份的独占串口读取 STATUS2、BATTERY1 和 SENSORS1，随后约每 5 秒读取后两者。观察到再次插入后重读 STATUS2。 |
| TCP 无有效状态，登记 USB 不存在 | 显示设备未连接。仅检查宿主 TTY 存在性。 |
| 9 秒无有效回复 | 关闭状态会话。新连接须经可信适配器重新核对身份并返回新状态。 |

约 650 ms 的设置页 Connection 刷新读取本地宿主投影。TCP 选中时，宿主门禁独立于页面计时器生效。回退期在打开 TTY 前后仍核对原 USB 身份。TTY 附着周期以宿主实际观察为准，健康 TCP 期间未观察到的瞬时拔插需要在真机验收。显式查询 USB、绑定核对和 USB 配网保留原入口。

## 证据

`npm run check`、`npm test`、`npm run build` 及 DSH `0.2.2-rc.5` 单包构建通过。全量 2105 项通过，无跳过。测试包括固件仓库的只读 C++ 对拍材料及实际 rc.5 的隔离加载夹具。

- 虚拟时间覆盖 3 秒探针、6 秒过期、9 秒清理、错误目标、错版本、坏字段、重复／迟到探针和新旧连接替换。模拟 USB 覆盖无设备无读、每次附着首读、恢复、实际取消信号及晚回隔离。
- 真实 loopback TCP 使用临时端口和测试专用载荷，核对收发状态、断开立即失效和资源清理。其身份是夹具前置条件。该场景验证宿主接口及真实 socket 生命周期。
- 隔离宿主通过真实本地 UDS owner 和 Connection 路由读取新投影。测试还覆盖网络可用时直接提交自动 USB 请求、原先取消再采样的兼容语义、离页与卸载。USB 短写及分段回复走模拟串口。
- 真机固件范围来自固件仓库 `docs/context/current-status.md` 及报告 `apps/round-pet/reports/2026-11-19-vp8-weather-https-task.md`。最新留驻为 0.1.29／ota_0，0.1.25／ota_1 回退。天气和自动校时有设备证据，Hub TCP 遥测仍待联验。

## 固件交接和回退

1. 定稿绑定身份、启动范围、撤销和重新认证。管理端只接收已认证适配器发出的状态，普通 VPC1 Pong 继续保留原控制语义。
2. 共同定义版本化状态帧、序号关联、字节上限、缺省字段和正负向量。优先合并控制与状态的心跳调度。约定重连、拥塞和失效时的实际延迟，并测 ESP 内存、功耗与设备侧租约。
3. Wi-Fi 配网继续 USB。天气地点和时钟的 TCP 写入待独立定义能力、授权、配置修订、设备持久确认和写入结果未知的恢复。
4. 现有日常 rc.5 单包和私有登记保持原样。新代码构建为工作区候选。未来若部署后需回退，按原单包报告恢复已安装的 0.0.8 快照及对应插件条目，沿用原登记与 Keychain 作用域。[已部署版本与回退步骤](2026-11-19-vp8-desktop-single-rc5.md)
