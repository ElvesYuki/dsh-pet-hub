## 实际改变和接口结论

新增默认OFF `createDshNodeControlConnection`，复用原scoped IPC、body/envelope/ACK验证与TCP19共享会话，仅在公开connection.fetch精确registry接GET controls/POST command。来源、用途及页面控制授权仍需可信resolve独立提供；没有自动发权/续权或文件路径/配置接口。原raw代理/Origin门禁不变，默认apply和peer兼容不变。

实际安装仍为rc.5：Connection /api先admit、精确Fetch再限owner、回调无Peer，browser Peer共享；Desktop旧转发删除Origin，不能放宽raw来适配。实际JS SHA0ebcca75…与400-15读取一致；manifest声明的types未在选定ASAR路径取得，本轮仅按JS契约评审。5份代码/manifest收尾复核保持；未启动DSH/profile、解析其cookie或读取凭据。

POST显式streaming避开上游默认大buffer，4KiB实读/声明上限与整体2500ms，严格JSON/UTF8/header/query和返回白名单。GET buffered避免GET携body。卸载abort/移路由、晚resolver不下发，已提交未知结果不自动重试；卸载不结束后台组。client factory增加闭合raw/connection策略，build/package加入显式Connection候选；默认bundle仍raw，两者不同时装配。浏览器发现旧全局页脚“不会下发动作”与授权控制冲突，已改为可信授权和设备首帧说明。

## 宿主验证和纠错

20项覆盖默认OFF、精确body模式/注册退出、独立许可、真实IPC CAS/去重、body/header/UTF8/JSON/query拒绝、读体及resolver期限、abort/卸载/晚结果、源失效、真实HTTP双层fixture身份、权限到期重领、构建slot加载、响应去敏、半注册回滚及stdin EOF/close资源退出。

首批16项有3项错误状态暴露：scoped IPC错误的稳定code存于Error.message，适配器初版仅取code，导致冲突/源失效/过期被错误转503。现与原raw入口一致，先以code或message查原白名单映射，再输出稳定错误；保留401/409断言，修复后16项通过，补边界至20项隔离CLI通过。测试没有放宽授权或将内部消息透传。

最终隔离CLI20/20、temporary_environment_removed=true；npm run check退出0，npm test含构建1804/1804（fail/cancel/skip=0，104527.30225ms），最终npm run build退出0。425条既有源码中420条SHA保持，修改5条、新增5条；TCP19后台/恢复、wire/codec/mapping和默认服务装配不变。候选模块/双bundle/exports/files/许可副本与文档链接核对见结构化证据；check仍仅语法检查，不称已有通用架构门禁。

## 当前边界与下一入口

本轮没有安装/启用插件、启动真实DSH或更改profile，没有生产listener、ESP/USB/固件/真实素材/现有pet或bridge操作，不提交推送。主线仍纯Node，零新依赖。旧400/360和全部回退保持；本轮不重新读取固件素材/运行其工具，也不推进生产准入。
