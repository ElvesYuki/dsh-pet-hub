# VP8 BOOT 私有登记与设置页宿主验收

2026-11-17。[Spec](../context/plans/vp8-boot-private-settings-spec.md) · [Diff](../context/plans/vp8-boot-private-settings-diff.md) · [联合回执对拍](2026-11-17-vp8-boot-proof-host.md)。

- 私有目录内新增版本 1 单设备索引。文件权限 0600，使用独占写锁、CAS、文件和目录同步及写回读取。验证坏档和遗留锁阻塞、写前失败不推进，以及 rename 后报错必须重开核对。索引只持有绑定身份、公钥摘要和密钥引用。宿主夹具中的签名器持有隔离 P-256 私钥。
- Node 登记报文进入固件实际 C++ `Session`。使用 OpenSSL 核对真实 P-256 签名，夹具模拟设备存储与按键。私有索引写入失败只发能力探测，不发挑战。持久回执故意遗失后，本地保留 pending。重开管理端并模拟设备重启后只发新探测和 fence。密钥引用缺失时仍保持 pending，恢复匹配引用及指纹后提升为 bound。
- 隔离 DSH Connection 夹具验证来源、显式授权、旧实例及修订，以及卸载注销。取消后迟到的结果被隔离，模拟连接关闭前作业槽仍被占用。默认客户端不注册 BOOT 槽，候选客户端分开注册。现有免输入查询在同一宿主的首绑前后都通过。
- 首轮全量回归发现常规客户端摘要受候选代码影响。改为独立客户端构建及独立宿主挂载后，原摘要与 PREP 检查恢复通过，沿用原审核门禁。最终 `npm run check` 通过，含 PREP 的专项 20 项及构建后全量 2,052 项通过，无跳过。

供隔离宿主使用的客户端为 `dist/client.boot-review.js`。常规 Desktop 客户端保持已审查的字节摘要。候选须由宿主显式调用 `mountVp8BootSettings`，提供授权检查、单会话接口和独立签名提供者。撤下候选宿主与客户端即可回退。恢复记录及密钥引用可原样保留以便对账。真机、当前安装 profile、原生串口排他、系统 Keychain、实体按键、冷断电及解绑均未在本次执行。
