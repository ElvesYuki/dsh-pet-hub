# 自然呼吸、阻尼回稳与桌面触摸原型

2026-10-29，按[Spec/Diff](../context/plans/character-natural-motion-spec.md)实施。当前候选为`.cache/layered-character/character-natural-motion-v3/`，使用既有character-master-v5真实21层母版。v1是初步参数检查稿，v2为调参及实际点击验证，v3补齐回放时的反馈文字同步；旧版本保留。

## 交付与操作

- `index.html`：可离线直接打开，贴图/脚本内嵌。点击右侧人物、试摸头/身体、关闭/开启呼吸、暂停、拖动回放及黑/浅底/2倍检查。
- 示例包含自然待机、摸头、身体反馈、连续点击后停止、停止回零、回稳时再点击六段。
- `natural-demo.webp`：360×360、12秒，来自288个实际浏览器Canvas采样。3秒摸头、4秒关闭呼吸、6秒身体触摸，随后回稳；时间线在`demo.json`。以24fps制作采样，WebP编码合并重复帧后233帧、累计12000ms。颜色质量90/alpha质量100仅用于观看，不替换PNG母版，不是设备帧率或性能结论。
- `scan.json`、`browser-check.json`、`browser-check.png`、`head-touch.png`：动作/覆盖/边界与回放检查证据；实际点击、透明区及2倍坐标换算证据另保留在v2/browser-check.json。

## 已实现的行为

纯逻辑`character-natural-motion.mjs`与DOM适配、页面模板分开；导出复用既有素材摘要/布局验证工具的显式`--natural`模式。均为制作工具，不进入现有插件dist或角色激活流程。

根矩阵恒等、主体位置/整体缩放不变。4.8秒不对称吸呼曲线驱动头肩相对微动，头部升降目标约0.45px、双臂微摆，身体基准不动；不通过整个角色缩放伪造呼吸。头部/发帽/头饰保持父子关系。16个有界弹簧通道包括头部旋转/升降、双臂、尾巴和全部11处发束；不预先合并头发或删减动态。

固定120Hz子步求解，发束受头部加速度影响，长发末梢还跟随父长发的位置/速度，呆毛采用较低阻尼独立回弹。停止待机撤去呼吸/轻风目标，保留位置和速度逐渐回稳。触摸只改变有界速度/短包络目标，不瞬移到新姿态；新的短反馈可打断恢复过程。

核心接360坐标与显式虚拟时间；页面先按实际显示矩形换算，再要求冻结底稿alpha≥16命中。头部和身体两类反馈，150ms全局冷却。核心只有最近一次短反馈，没有无界事件队列；页面回放历史最多400项，每段制作预览最多60秒，可重播。拖回过去再点击会丢弃该时间之后的事件，形成新时间线。暂停/隐藏页面冻结动画时间，避免追赶长段墙钟；这些是宿主预览策略，不冒称已有设备时钟/触摸实现。

五官仍为中性资产：没有新笑眼、眨眼、情绪或口型。头部动作是正面平面轻摆，没有新增侧视图或网格形变。

## 验证

| 检查 | 结果 |
| --- | --- |
| 24fps与60fps调用相同固定步长核心 | 相同最终通道状态 |
| 根矩阵、发帽/头饰继承、末梢支点链 | 通过 |
| 点击/停止瞬间的姿态连续 | 保持原位置；停止保留已有速度 |
| 1800次快速交替点击 | 冷却有效，所有角度/速度始终有界 |
| 停止并回稳 | 无残留反馈；测试中各通道位置/速度收敛到0.0001以内 |
| 非法/倒退时间、非法坐标、超长回放 | 显式拒绝 |
| 实际浏览器点击人物 | 触发头部反馈 |
| 2倍显示后的PointerEvent坐标换算 | 身体反馈正确；透明区不触发 |
| 暂停、拖动、回放反馈文字 | 时间保持；头/身体提示与当前帧一致，回到触摸前不残留旧提示 |
| npm run check / npm test | 通过；178/178测试（本轮新增5项） |

以冻结底稿密实内区（alpha≥240、方形侵蚀半径4px，31423像素）寻找alpha<200候选，六段各采样12秒、24fps含首尾289帧，共**1734帧**。全部最差候选数为0，alpha≥16像素越出半径166.5安全圆的采样为0；各段动态可见包围并集为[70,49,282,315]。局部运动带来约1px的边缘覆盖变化，未修改人物基准比例/原点，不以自动居中或截断图像伪造通过。

浅底放大检查了头部与身体反馈关键帧，颈部/肩口未见新的透明细缝。该计数只针对透明覆盖，不能证明全部发际过渡边色、发束形变或自然观感已最终验收。微风和回弹参数仍可根据用户观感调整；当前小幅动作不能推广为大角度抬手/转身能力。

临时白名单loopback服务均已关闭，浏览器离开测试页以释放其动画回调。没有连接pet/DSH/设备、修改固件、安装依赖/插件、改变既有服务或提交推送。未进行设备FPS、触摸端到端延迟、音频或长期资源测量。
