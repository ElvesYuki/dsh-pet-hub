# M1六动作400素材候选 Spec

2026-10-30，实施前。本轮用户授权M1小样：0、2、15、42、56、65。只在本仓库生成素材并验证宿主解码，交付设备侧合同；固件、烧录、运行服务、正式360包不改。

## 固定合同

- 400×400、源裁区(124,-6,400,400)、alpha合成黑底、无缩放／额外安全圆，466屏居中偏移33。先以RGB格式处理，不让YUV裁区自动对齐改变几何。
- 源24fps保持：0/2/15/56/65为241帧，42为118帧（118/24秒），不补帧／变速。ID和来源SHA保持。
- PET4：既有532B头、RGB565的256项调色板、key12／flag1、20行tile、LZ4 block和XOR差分、每帧索引CRC与offset表不变；400的tile原始长8000B。最终recipe为本仓库原创加权median-cut调色板＋无抖动最近色映射＋本机已安装liblz4 HC12；原创greedy LZ4保留作独立参考／合成测试，最终重打包不改索引或像素。库不复制／打包，包装脚本原创；不冒称与旧360调色算法相同。
- 空间不重采样不代表颜色无损。测量最终调色板RGB565相对合成黑底源RGB8的逐通道绝对误差、最大误差；保留源与编码后同帧图／完整动画对照供用户验收。
- 严格400 profile仅显式native400-candidate-v1开启，24fps／1–241帧／key12／flag1，宿主文件上限16MiB，仅离线审查包络，不是设备或正式导入上限。默认240/360、公开decodeLz4的7200B上限及所有生产导入路径不放宽。

## 实施与验证

先新增原创编码模块、合成测试、离线小样工具；已有decoder仅加入显式候选profile与内部8000B受限block路径，未知profile拒绝。候选manifest与正式index/namespace分开，记录几何、recipe、许可、源SHA、每文件SHA、帧数／时长、索引/RGB摘要、最大块、文件大小、量化误差。实际包超宿主上限则失败，不隐式扩大。

工具逐个源SHA复核，使用已安装ffmpeg解码RGBA；黑底合成后的400RGB8原样落临时文件，源坐标映射抽样逐像素复核，再以单帧缓冲编码。每动作完成后删自有临时原始像素；输出只进新.cache目录，不执行固件脚本或复制上游实现。

测试覆盖LZ4匹配／重叠／末尾、400默认拒绝／显式接受、未知profile、几何／帧率／帧数／长度／CRC损坏、118帧无补齐、随机seek与最后帧；用已装liblz4做独立全帧解码对照；旧240/360全套回归。CRC/摘要不能替代画面质量认可，PC耗时不当ESP性能。

本轮已另用显式外部liblz4逐块解码所有1323帧、重算索引CRC/SHA并HC12重打包，宿主候选decoder复核最终字节；本轮不打通M2的worker／IPC／代理／正式素材导入／角色激活，不把400视为已支持设备。独立预览只读候选字节，主界面／分层360保持。固件侧下一任务须按本合同显式适配宽高／tile缓冲／帧数／包大小／LVGL(33,33)／damage及回退，重新测量，不只放宽头检查。
