# PMA1 单动作 LAN 联调调用者

2026-11-12。默认关闭的人工入口沿用 PBP1 BOOT 配对、正式 PMA1 sender 和许可。只接受一次动作 1、固定的本地 RFC1918 IPv4 和非零端口。启动前固定完整 BEGIN 字节及 SHA，库存的根和代数由实测侧只读提供。监听就绪后从已激活 RAM 配对发一次 PBP1 type 5。等同作用域 Active/OK 后才允许首条 TCP 连接进入认证及发送。PMA1 校验配对、boot、目录与独立批准，沿用素材预验、背压和 `Saved` 回执。普通 loopback 入口不变。

ARM 与 Wi-Fi 仅在 RAM，USB 独占并保持至实际 TCP 与文件退出。单次接入，超期、坏回执或断线关闭，不重发 ARM 或尝试第二条连接。断线不补造 `Saved`。验证只用隔离宿主、合成输入和回环，真实监听和设备操作由固件任务负责。

首轮实板数据未在 30 秒内送完。管理端接受的 LAN socket 显式启用 TCP_NODELAY，对齐既有回环与终端拨号。增加单调时钟聚合，区分总耗时、TCP 工作耗时、DATA 写回调成本、有效 ACK 等待和末块未确认等待。统计只纳入原身份、作业及累计字节校验已通过的 ACK。单块在途、认证、完整校验和原 30 秒上限保持。
