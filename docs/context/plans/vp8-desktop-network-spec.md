# 桌面宠物设备 USB Wi-Fi 配置 Spec

2026-11-18 起草。沿用 DSH rc.3「桌面宠物设备」设置槽和已启用的独立绑定后端。固件 DESKNET2 供本切片使用，设备自身负责联网、SNTP 和天气。固件文件、现有 DSH profile 与运行服务仅作参考。

- 后端在同一独占 USB 会话核对持久绑定、Keychain 公钥摘要和索引 revision，再执行 INFO。SET/CLEAR 先收到同会话的 DESKNET2 INFO，再执行一次用户要求的命令。现有绑定、查询、电池和传感器共用既有 USB lease，释放完成以前不允许其他操作占有。
- DESKNET2 使用随机 8 位小写十六进制 ID，按请求类型和 ID 严格核对回执。`saved`/`cleared` 来自持久写回执。界面将持久结果与 INFO 观察的联网状态分开。INFO 缺失时可同会话只读尝试 STATUS2，提供版本信息和 DESKNET2 不可用提示。无 DESKNET1 写入降级。
- 丢失或无效写回执、关闭或断线造成写入不确定时显示结果未知。前端要求重新读取状态后才恢复写按钮。INFO 仅提供当下有无配置，不能确认某一版凭据已写入。没有自动重发。卸载中止等待并排空 USB；串口释放失败冻结原有 owner。
- 表单显式点击提交或清除。密码使用非受控字段，不进入 React 状态、配置、日志、命令行或回执。请求使用受限二进制体，独立密码尾部不经过 JSON，应用持有的字节缓冲用后清零。浏览器原生输入及网络栈的内部临时副本由宿主管理。
- SETTINGS 路径继承 Connection 的同源、授权、精确路由和卸载门禁。只有已登记的共享 USB 实体目标提供候选能力，绑定和查询目标有冲突时拒绝。旧主包与新后端继续用原查询和绑定；新主包遇到旧后端给出明确缺失提示。
- `POST /api/pet-hub-vp8-boot/network` 读体上限 1,024 B，读体及授权窗口 2.5 秒，USB 使用既有 job 及单次交换期限。元数据携 owner `instanceId`、`revision` 和 `info`/`set`/`clear`，只有 `set` 接受新配置字段及密码尾段。SSID 最多 32 个 UTF-8 字节，密码为 8–63 个可打印 ASCII 字节或开放网络用的空值。UTC 偏移为 -720 至 840 分钟，天气可选，坐标四位小数。默认 NTP 为 `pool.ntp.org`，UTC 偏移初值取当前桌面时区。
- 使用合成数据覆盖字段边界、错误关联回执、旧固件、只读 INFO、写入未知、并发与关闭；在临时环境编译固件公开命令解析头进行 Node/C++ 请求对拍，另验证两份 rc.3 打包候选。真机写入、断电留存、STA/时间/天气和实际 DSH Connection 尚待独立窗口。

## 2026-11-19 宿主验收窗口

固件任务在使用已连接的圆屏。本窗口只在 `ELECTRON_RUN_AS_NODE` 子进程中装配已安装 rc.3 的 Cordis、Connection 和候选包。使用数值 loopback 动态端口、临时工作目录、合成凭据和 USB 夹具。Desktop 转发单独执行安装包内的转发函数，并记录和完整 GUI 窗口的覆盖差异。无 DSH profile、实体串口扫描、原绑定索引或桌面 Keychain 访问。先验证原查询、授权门禁、配网读写和撤销，再退出自有进程并清理。实板阶段待固件端明确版本与串口交接，先做只读 INFO，写配置由用户显式操作。

固件侧随后完成交接并授权一次只读联验。沿用同一独立进程和本机认证 HTTP，改用原已登记 USB 目标、原 Keychain、发布包的绑定 owner，只从发布设置页发一次 INFO。测试载体额外拒绝其他写请求。检查 `deviceChecked`、联网字段、绑定索引摘要和卸载。日常 profile 和窗口不参与，若串口无法取得则使用既有宿主和固件实板证据对照。
