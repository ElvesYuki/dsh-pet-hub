# 完整角色包与原子激活 Spec（实现前）

2026-10-29，仅离线simulation/streaming。新增package_schema=2：semantics完整映射idle/thinking/working/result/success/waiting/error/touch到包内action_id；每动作明确fps、frames、loop(loop/once_hold/once_idle)。idle必须loop，引用不存在动作/未知规则拒绝。所有字段纳入原manifest摘要及index摘要，旧包保持兼容但不猜测语义/自动升级为可激活完整角色包。PET4物理24fps约束不变；包fps/frames须与实际二进制一致，不能改JSON伪造帧率。

每设备独立原子激活：只从已发布且完整登记的仓库版本选择角色/变体。先固定目标版本引用，独立候选worker重验全包、能力与当前语义动作、解码首帧；旧worker/旧actual继续可用。全部通过且设备激活revision/在线会话/来源状态未变、未取消时，先将完整设备激活指针集合原子写入role-activations.json，再同步切换该设备运行引用；最后关闭旧worker。候选失败/磁盘失败不改旧指针/actual。不是设备Flash事务或掉电绝对耐久保证。

指针含device_id/revision/version_id/character_id/variant_id/manifest_sha256；独立于早期“素材偏好”文件，UI明确区分偏好与已激活包，避免将旧偏好当生效状态。重启只恢复已确认指针并后台重验，建立新模拟播放时钟，不恢复命令/租约/手动意图；离线设备记录仍保护仓库。只允许一个候选任务，当前两设备最多各一个激活worker，基础导入worker另计；不推广实物容量。

新角色调度复用模拟source与虚拟时钟，不重复监听DSH。自动语义按包映射，不硬编码旧8动作编号；手动可选择包内任意动作，回auto立即使用最新来源。动作loop循环、once_hold停末帧、once_idle播完转idle且不每tick重播原一次动作；新意图/新来源事件才重播。同设备切换失败保留旧actual，不影响另一设备。未在线不提交新激活或帧；重连重建播放会话。

IPC：状态展示激活指针/实际帧及后台任务；activate返回任务ID立即响应，不让HTTP等待全库校验；cancel只取消候选，intent带每设备revision CAS。服务重启/旧实例/并发过期请求拒绝；异步回调绑定任务/设备代数。清理保护持久激活、实际/待定目标与候选版本。新激活操作与清理互斥，候选持有版本pin贯穿准备和提交。

UI从仓库列表审阅可激活的完整包，再选择目标设备启动激活，显示任务失败/取消/成功及旧/新实际播放；提供包内动作手动与auto。旧包显示仅偏好用途。所有素材/测试为原创合成，真实包若验证需显式从已核对非商用来源构造角色元数据，不写外部仓库/配置，不复制动画到Git。
