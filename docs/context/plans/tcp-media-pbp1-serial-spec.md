# PBP1 独占串口适配器

2026-11-12。按候选 `afa4897f` 的固定 PBP1 协议，通过显式指定的 TTY 给现有配对编排器提供 `exchange` 与 `close`。仅做宿主代码、PTY 验证和人工入口。实物由固件任务负责。

- 宿主非阻塞打开指定字符设备，由短命 POSIX helper 在同一描述符取得 `flock` 与 `TIOCEXCL`，配置 raw、关闭硬件流控和 HUPCL，保留速度。禁止自动复位、主动 DTR/RTS、扫描和真实设备测试。明确驱动打开瞬态与已有第三方句柄的边界。
- 按 magic、STATE 类型、固定长度、CRC 与状态字段从混合输出提取有界帧。读前丢弃积压，事务间清除部分帧，单次超时不重发已提交请求。PBP1 无逐事务关联字段，仍由编排器校验 boot、device、proposal、指纹和相位。部分写入失败时关闭该串口，避免把后续 INFO 拼进残帧。
- 人工入口需要指定串口和预期 device ID，从终端输入屏幕指纹并提示松手后长按。验证入口退出时撤销本进程租用。无串口原始日志、PSK 落盘、服务或 LAN 装配。
