# VP8 BOOT 私有登记与设置页候选 Spec

2026-11-17。联合回执验收后，装配单设备 BOOT 首绑的隔离宿主候选。生产宿主及现有免输入设备查询保持原装配。本阶段仅用临时目录、宿主控制的 USB 夹具和隔离签名器。真机前另行验证端口身份、串口排他与关闭、系统钥匙串及实体按键。

## 私有索引和顺序

宿主显式提供权限受限目录。单记录版本 1，记录为 null、pending 或 bound。保存完整设备、控制者、绑定 ID、代数、公钥 SHA-256 和不含秘密的签名密钥引用。用独占写锁、CAS 修订、私有临时文件、文件同步、原子 rename、目录同步和读回确认。坏档及既有锁保留。rename 后错误冻结当前实例，重开读取真实结果。密钥由独立的受信签名器持有。设置页、记录和日志都不接收或存储私钥。

先核对候选能力、当前设备及未绑定状态，再从注入的密钥提供者取得签名引用。先关联并提交 pending，之后才申请挑战、签名提议。复用 PBP1 首绑签名正文，校验本地 P-256 签名和 132 的等待身份。poll 使用新 nonce，只有 133 的完整回执才能提交 bound。登记失败、掉线或取消后保留 pending。恢复重新探测同一设备，只发 fence 对账。成功 fence Unbound 清除 pending。Bound 必须重新核对精确回执及引用对应的完整公钥指纹，冲突、丢钥和存储故障保留待恢复。密钥清理与系统钥匙串实接留待后续。

## 设置页和宿主边界

独立于现有查询卡片的候选设置区。挂载时只读本地状态，用户明确选择登记、对账或停止等待。仅显式提供已授权的候选宿主，并通过现有 DSH Connection 模式接入。提供者授权、应用 origin、精确路由、实例与 U64 修订都需核对。只投影阶段、修订和实例，不传输端口、设备身份、密钥引用、nonce 或原始回执。新请求不能抢占在途作业。取消或卸载宿主立即使旧响应无法提交，作业槽持有到关闭完成。离开页面只停止轮询。浏览器和生产宿主缺少候选入口。

暂不接真实设备，不烧录，不安装插件，也不改变现有 DSH、pet、桥接服务、已登记设备配置或免输入查询。回退由撤下候选接线完成，保留未知结果的索引供后续对账。
