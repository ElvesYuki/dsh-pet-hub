# VP8 一键绑定同进程配置候选 Spec

2026-11-17。固件任务报告候选通过真板 CLI 首绑及跨进程密钥读取。管理端本轮只实现、验证与打包，不连接真板、不读取现场凭据、不修改已安装 DSH、pet 或 Hub。使用已打开的 DSH 作为后续部署目标，不启动第二个窗口或宿主。

## 启用与生命周期

独立包 `dsh-pet-hub-boot-review` 增加 rc.3 原生设置 `enabled`（默认 false）与 `enrollmentDirectory`（默认空）。只有二者显式设置并确认 macOS Electron Desktop profile 才装配 op3 owner。无启动环境回退。启用只打开现有私有索引，复用原 Keychain、签名引用、已确认 USB 身份及串口排他；启动和 GET 不探测设备。普通 Hub 包与免码查询保持独立。沿用 rc.3 Connection owner cookie、内部 URL、精确路由及实例修订。

同一进程只允许一个候选 owner。停用立即撤销授权、路由及在途尝试；等待串口关闭及所有旧异步完成才允许下一次加载。新实例使用新 revision 会话范围。关闭失败阻塞重开，必须由操作员核对资源释放。只交付配置片段和本地包，默认安装状态不变。

设备初次接线、复位或启动时有界 Type 6 无响应，显示可重试的接线／就绪状态。只有收到合法能力状态才判断固件不支持。手动重试从新的只读探测开始。已有绑定只核对，待确认记录走恢复，只有新的明确点击可开启首绑。

## 密钥作用域与长期位置

当前引用由目录名 `vp8-boot-review-<scope>` 和设备 ID 导出。长期用途保留原目录名与 Keychain 文件、私有解锁文件、索引和明确选择的 USB 配置。调整 JS 和 native helper，使其识别账号下受限的长期父目录。迁移用一次性合成凭据验证，保留源目录供回退。禁止生成替代私钥、改标签、重绑设备或仅凭文件复制验收。长久目录只有在相同公钥摘要与实际 P-256 签名通过之后才建议切换；若系统 ACL 拒绝，退出并保留原址，不自动修改 ACL。现场临时根不迁移。

## 验收

宿主测试覆盖默认关闭、坏配置、同一进程启用／撤销、在途关闭和旧回执、旧实例拒绝、现有免码入口回归。只有实际合成 Keychain 的签名实测才可标记迁移通过。可回退包含启用和撤销配置片段，不包含密钥、注册数据或本机配置。
