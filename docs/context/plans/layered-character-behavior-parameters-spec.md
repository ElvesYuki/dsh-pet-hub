## 不变量与修改

- L1已冻结的behavior JSON与profile版本/允许值保持不变；新增统一入口校验完整behavior并复制为冻结快照。未传参数的旧API使用同一基线。拒绝缺键、未知字段/版本、改值；运行中外部修改不能影响已创建求值器。
- 自然动作、状态/表情、无音频嘴型、挥手与轮廓纯逻辑移入core；scripts保留原导出名作为兼容入口，不复制两份求值器。core不导入DOM、磁盘或DSH。
- 工厂/replay/sample接口追加可选behavior；保持既有时间校验、返回结构、异常与事件顺序，参数替换不重新组合浮点运算。旧不启用states的自然动作保留原臂限幅/速度兼容值（不属于当前包profile）；包内模式固定开启states，仍按L1合同。
- 现有HTML导出器将新core依赖按固定顺序内嵌，显式传入同一behavior并记录摘要；自然预览的各通道/轮廓绘制消费该快照，不加载包内JS。不实现目录包导出/加载、首帧替换或异步候选管理。
- 360大小/原点、素材、11动态发束、46动作、真实音频/设备安排均不改；不安装依赖、不改运行服务或固件。
