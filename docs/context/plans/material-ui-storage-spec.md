# 每设备素材界面与持久化 Spec（实现前）

2026-10-29，仅显式simulation模式。复用MaterialCatalog/Assignments；为sim_A提供合成466屏能力、sim_B提供合成240能力，元数据选择与原240动作actor分离。不得宣称换包会改变模拟播放器或实物。

服务取得UDS所有权后才加载独立materials.simulation.json（私有runtime目录0600、限制128KiB、schema1、最多64设备、严格字段）。存已确认角色/变体/摘要/required_actions及每设备revision，不存素材、令牌、能力缓存或播放状态。加载损坏/权限不安全则启动失败且保留文件，不自动清空。未知设备记录保留，变化目录/能力重新resolve，不自动换包。

保存：服务唯一写者、每设备revision CAS、service_instance_id防旧页面；校验全部通过后先写同目录0600随机临时文件、fsync文件、原子rename成功后更新内存。失败不增加revision、不显示保存成功；不承诺断电下目录元数据耐久。禁用模式不读写该模拟文件。

状态接口在每设备material字段返回白名单候选、当前选择/兼容状态/呈现方式；不暴露路径或凭据。POST /v1/materials/selection仅simulation开放；插件代理同源JSON白名单转发，409保留，磁盘失败503。不自动重试写入；响应丢失刷新当前选择供用户核对。

UI每设备显示合成屏幕和当前已保存选择、可选变体及明确保存按钮；推荐不等于已选。选择暂存在React组件，不被轮询覆盖，成功/冲突刷新后重建；不兼容选择可见、无候选禁用保存。标明“仅保存偏好，未安装/播放”。卸载取消请求。

验收：A/B独立选择；服务关闭/重启恢复选择与revision、播放状态不恢复；双客户端冲突；错误摘要/设备/字段/旧instance无写入；磁盘失败不改内存；损坏/权限不安全不覆盖；默认禁用无文件；真实插件代理和组件交互宿主测试。无真实DSH加载/设备操作。回退只移除本仓库新增代码与独立模拟文件（关闭临时服务后），不触碰现有配置。
