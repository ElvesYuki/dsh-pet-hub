# 同仓后的共用运行层整理

2026-11-20。设备设置、登记、升级和连接共用的系统能力按职责归属，历史候选仍通过原功能入口验证。

## Spec

- 独占 TTY 打开和配置独立于 PBP1 分帧。native 助手继续由调用方编译并通过绝对路径提供。保留 fd 3、独占、非阻塞、释放失败标记和已有错误码。
- 局域网归属判定只检查原有三段 RFC 1918 IPv4 范围。调用方继续各自核对接口、子网、绑定和接入许可。
- Node 请求体读取沿用 4 KiB、2.5 秒、严格 JSON 和取消后继续排空的约定。权限、路由和对外错误映射保持由各入口负责。
- 保留被调用的历史兼容、模拟和诊断入口。无现行源码、构建或测试引用的观测器从工作树移除，历史验证向量仍保留。
