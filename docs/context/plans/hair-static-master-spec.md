# 十二层头发静态母版 Spec/Diff

2026-10-29，用户授权按计划实施。以已冻结360标准底稿为唯一像素/位置基准，先交边界标注、12层透明素材与真实合成对照；不加动态，不考虑性能删减，不改原46动作或设备。

## 方法与边界

- 将拆分边界、父子关系、试标支点和绘制顺序写入可编辑制作布局。可见区域通过SVG路径/遮罩引用原底稿，使用既有离线渲染工具导出，而不是重新生成整个人物。
- 分离hair_cap、三束刘海、左右侧发、左中右后发、呆毛和左右末梢；头饰、耳鳍、尾巴保留在静态其余层，不纳入发束动态。
- 遮挡补画使用内置imagegen制作局部制作参考，保留透明输出与提示词。生成结果与精确可见区域分开，未经静态/遮挡检查不混入原像素基准或称完整动态资产。
- 在可见面零误差版本之外，另建补画母版候选：将AI后发填色场用于发束多边形内被其他层遮挡的区域，头部底色另成层；保留每层原可见像素，填色仅限原角色密实覆盖范围，源场坐标显式记录。真实合成测量与原稿差异，不以原可见面零误差替代补画版本检查；动态/支点仍待验收。
- 所有导出图360×360、共享原点，不按每张包围盒自动缩放/居中。合成必须真实使用独立图层，不用AI再画的完整角色冒充合成。
- 检查图层alpha、覆盖重叠/遗漏、实际合成与底稿像素差异，目视单层是否混入眼睛、服饰或配件。不能只靠完整静态像素一致就宣称分割语义正确。
- 原图与派生素材仅写.cache下新目录，署名/许可沿用THIRD_PARTY；不进Git/dist。新增布局/工具/测试为原创MIT。

## 交付

拆分布局和标注预览、12张透明PNG、保留非头发部分的rest层、真实静态合成PNG、分层可开关预览和机器检查清单。支点为制作试标、并非设备已测；隐藏面补画和运动露缝需单列状态，尚未完成时不得称可直接动画。

测试布局完整性、父子引用、分割遮罩覆盖及源摘要冻结，npm run check/npm test。真实美术的边缘/遮挡与合成另作图像检查。本轮不启动设备或运行服务，不重做整套动作。
