# 多设备素材变体 Spec（实现前，2026-10-29）

同角色多变体，设备物理显示与素材尺寸分离；纯core离线实现，不接设备/DSH/固件。保留schema1等尺寸四槽合成fixture；新增schema2明确exact/center呈现白名单及单动作RAM、Flash激活/暂存容量。不得隐式缩放、裁切或编码转换。

新增素材目录：验证角色/变体唯一性、摘要、动作长度/编号、许可引用；同角色不同大小共享语义动作ID。按已验证能力筛兼容变体，优先exact再较大原生center、稳定ID排序；推荐不写分配。用户明确确认指定变体后按每设备revision CAS保存内存分配；不兼容/不存在/无变体不回退。能力改变重新检查，原选择保留并标unsupported。

schema2表示离线候选能力，不宣称当前固件已报告新协议。DeviceModel仍是schema1四槽参考模型，遇schema2明确拒绝；本轮不伪造Flash安装/掉电恢复。生产持久仓库、UI选择器、注册表多manifest装配、v5迁移及去重生命周期另列后续，不通过内存分配声称已完成设备安装。

验收：466屏+360素材center、240圆屏、矩形屏、编码/容量/形状/呈现白名单拒绝、exact优先、手选更小变体、CAS/跨设备隔离、能力变化不自动替换、非法目录/重复变体/缺动作、schema1回归。运行check及全套test，禁止复制真实素材或凭据。
