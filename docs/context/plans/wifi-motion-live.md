# 多 Wi-Fi 与 DSH 扩展动作真机验收

## Spec

沿用日常 DSH、当前 Hub、现有持久绑定和 USB，先确认版本及 TCP 实时状态。DSH 只选独立测试会话。等待、失败和持续整理分别核对动作 41、42、43 的设备回执。只从真实任务状态触发，分别记录宿主状态、设备接收、设备首帧及人工目测。固件提供的动作缺失回执可以作为单动作证据。板上无可读素材清单时，不用本地素材库推断实板库存。触摸由现场操作，重连验证只中断测试设备链路。

通过设置页先只读查询 Wi-Fi 列表和当前连接项。写入仅使用有明确授权的备用测试网络，先确认有空闲项，并能保留现有全局校时和天气参数。SET 如会覆盖未知的全局配置，则保留只读，记录缺少的基线。写入未知须新读列表，禁止盲重试。逐条移除仅对本次新增的测试网络执行。

## Diff 与回退

使用设备页现有入口，不更新固件、不写入素材。临时联动结束后恢复原来源选择，核对设备仍可读取。如已有接口未公开设备动作回执，先评估最小本机观测方案，观察仅记录动作、结果和时间，修改运行包前保留当前包和配置。联网测试结束撤掉测试配置并核对日常连接恢复；恢复条件不成立时不开始写入。

预检发现日常 Hub 仍转接旧签名助手，但它原先的临时目录已缺失。按既有恢复契约，使用同作用域、绑定索引与数据库一致的私有备份恢复到原址，再验证现用入口能够用同一密钥签名。恢复只补回缺失的目录，保留原备份、现用索引及插件配置。同时记录 Hub 配置的 LAN 地址当前是否属于本机。恢复签名不会改动这项配置。

用户授权修正日常 Hub 的 LAN 监听地址。只将地址换成旧地址所在网段中唯一的本机私网 IPv4，先私下备份配置，保留端口、其他配置和插件。只重载 Hub，检查绑定与 TCP 状态；失败时从备份恢复该字段并重载。如需验证备用网络，由用户在本机输入，不采集凭据。

当前候选的动画联动表单显示任务状态。设备的播放回执已在核心校验，但没有页面读口。真机验收可临时使用独立模块路径的本机探针，复用原 TCP 和状态来源，仅记录枚举、动作、连接序号及宿主单调时间。先核对探针语法与宿主对照。记录成功或失败后移除探针，复核候选原入口和联动关闭。原版和旧路径转发均可恢复。

## 2026-11-24 现场记录

- USB 读回 `0.1.40-l-battery-usb-pair-test`／`ota_1`。旧签名助手原路径缺失时，日常页面只能确认本地有绑定，Wi-Fi 查询失败。长期私有备份与现用登记索引的绑定字节、Keychain 数据库、解锁文件及串口输入一致。恢复后现在用的转接入口随机挑战验签通过，真实页面重新显示已从设备核对持久绑定。
- 初始 Mac LAN 地址变化使监听装配拒绝启动。备份原补丁后只更新 Hub 地址并重载 Hub。原页面恢复 TCP 实时状态和绑定核对，其他插件配置及 `dsh-pet` 清单复核一致。
- USB 实机列表返回在线模式、已联网、已保存 1／4，并标出当前联网项。恢复 TCP 后一次 USB 查询未成功，重新读取后返回相同数量。这是已绑定的 USB 列表读取证据。设置页的 Wi-Fi 写入、重启留存和网络轮换另记。
- 用户在本机页面提交备用网络。原保存提示在切换页面后无法回看，重新通过 USB 读取确认已保存 2／4，原联网项保持。回读曾遇一次暂不可用，未再提交写入。用户确认同一 SSID 再次保存成功及圆屏重启。重启后独立 USB 读回两项，验证列表留存和原网络连接。移除本次测试项后读回已保存 1／4，并再次确认仅原网络处于联网状态。未验证更换后的备用密码能否联网，以及首选网络失联时的自动轮换。
- 圆屏重启后设备恢复 Wi-Fi，但日常 Hub 仍显示 USB 状态。重载 Hub 后重新建立认证 TCP。现协议的设备 LAN 端点只存 RAM，Hub 登记 owner 每次挂载仅允许一次 ARM。重启后的自动重新 ARM 单独跟踪。
- 本机首帧探针配合真实 DSH 专用会话。内置问询工具进入等待后，动作 41 关联请求在同一认证连接收到 `Accepted` 和 `Presented`，显示序号 2。从发送到首帧回执 472 ms，单次样本。素材当前可呈现由设备回执确认，未现场目测整段。
- 第二个真实任务的终端工具返回后，DSH 持续处于整理。动作 43 在状态进入后 1,001 ms 下发，同一认证连接收到 `Accepted` 和 `Presented`，显示序号 7。发送到首帧回执 728 ms，单次样本。普通工具失败和用户停止均不替代 `turn/end` 的真实失败原因，动作 42 尚无实板首帧证据。
- 收尾前未观察到圆屏本机的离线再上线事件，同一 Hub 下的短时断线和旧动作不重放未判定。恢复联动关闭，移除临时观测模块，恢复原候选入口。原窗口显示 Hub 运行中、TCP 实时状态和原持久绑定核对。未烧录或安装素材。
- `npm run check` 和 `npm test` 通过，2,126 项通过、11 项跳过。候选的本机探针通过 Electron schema 对照和用合成回执验证的宿主测试。
