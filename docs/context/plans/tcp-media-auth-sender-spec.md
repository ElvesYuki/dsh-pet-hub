# native400 管理端 PMA1 发送器接线

2026-11-11。终端已经用独立 C++ 实现完成共享向量和真实素材认证回环。管理端提供默认关闭的显式 PMA1 入口，只接调用者交付的 IPv4 loopback socket，复用当前 sender 的来源身份、只读 fd、双遍 SHA、单块背压、进度、取消和同 boot 查询。

- 固定作业 ID 与 BEGIN 字节后，在已认证的正确设备和目录上预验素材。可信同步授权回调绑定完整 BEGIN、源身份、配对代、用途和单调截止。决定在首次尝试发 GRANT 前消费一次。BEGIN 可能已出站才允许记录 Unknown 或发 CANCEL，取消和关闭等 fd/socket 真正退出。
- 每连接按 repair/query 重新握手并读取同一受信绑定代的密钥租用，校验 D_INIT、双方证明、严格序号、模式、方向和标签。默认拒绝裸 PTM1 降级。到期或撤销关闭连接，提交结果不明时保留 Unknown。只允许持原作业显式 QUERY，不重放 GRANT 或 BEGIN。
- 提供进程内配对材料接口和未来物理 USB 配对交接。测试只用合成密钥。既有裸 PTM1、PTC1、DSH、pet 和 bridge 的入口与权限独立。无生产装配、真实配对或设备操作。
