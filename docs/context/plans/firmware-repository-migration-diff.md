# 圆屏固件并入 Hub Diff

2026-11-20。变更和验收边界见 [Spec](firmware-repository-migration-spec.md)。

| 现有位置 | 迁移位置和改动 |
| --- | --- |
| 固件仓圆屏日常构建及源文件 | `firmware/devices/esp32s3-touch-amoled-175c/`，用同一源提交导入，调整 CMake 相对路径和源码职责名称。 |
| 圆屏板级 BSP、SDK 默认和共用依赖 | `firmware/devices/…/` 与 `firmware/components/`，只收录目标构建实际使用的部分，保留 SDK 组件锁。 |
| 固件 C++ 测试与验证工具 | `firmware/tests/` 与 `firmware/tools/`，更新包含路径及输入参数；Hub 对拍改用本仓路径。历史原型和非产品构建维持独立的回退文档。 |
| 固件活跃的协议说明和共享字节向量 | `docs/protocol/`，同步调用方引用，保留版本字段、收发字节、拒绝条件和签名用途。 |
| 固件仓外部素材路径与显示参数 | `media/profiles/400x400/` 保存规格和清单。生成输入通过显式参数提供；转换只复用原冻结身份。 |
| Hub 许可、项目说明、忽略规则和上下文 | 登记导入来源和适用许可证，排除本机编译产物及缓存，写入实际验证记录和迁移完成状态。 |

验收从源提交清单开始，通过后依次验证宿主、Hub 和交叉编译。线协议、持久化格式和板上行为的变化须单独立项。工作区回退以评审后的 Git 差异为单位，现场回退用原备份；本轮只离线构建与验证。
