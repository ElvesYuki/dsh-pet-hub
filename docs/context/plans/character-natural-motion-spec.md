# 自然呼吸、阻尼回稳与触摸反馈 Spec/Diff

2026-10-29，用户明确授权。沿用v5真实21层母版，输出新的离线桌面预览；不修改原360底稿/46动作、固件或现有运行服务。

## 实施

- 纯逻辑模块与浏览器渲染/输入分开。根矩阵固定，不做整体缩放、自动居中；用头肩的微小相对位移/旋转表现呼吸，身体基准不动。
- 以固定120Hz子步求解阻尼弹簧，驱动头部、头部升降、双臂、尾巴及全部11处发束。后发响应头部加速度，末梢额外跟随父长发速度，呆毛独立回弹；正常呼吸、停止与触摸共用连续状态，不重置姿态/速度。
- 头部和身体两类触摸，桌面将实际点击坐标换算到360后做角色alpha命中；核心只接坐标/显式时间，不依赖DOM/DSH。150ms全局冷却，最近一次短反馈替换目标包络，有界角度/速度，不保留无界事件队列。
- 停止待机时撤去呼吸/微风驱动，保留已有位置/速度自然回稳；新触摸可中断回稳。暂停冻结虚拟时钟，隐藏页面自动暂停，避免恢复时追赶大段墙钟。
- 提供真实点击、摸头/身体示例、停止/恢复呼吸、暂停/回放、黑浅底、支点与低覆盖诊断；保留全部11处效果，不进行性能删减。本轮五官仍为既有中性图，不冒称已完成表情/口型。

## 验证

测试固定步长在不同采样频率下的一致性、静态根不变、停止收敛、触摸中断无姿态跳变、限频/连续点击有界、非法与倒退时间拒绝。浏览器实查命中/透明区、暂停/恢复、停止/再触摸和回零，扫描自然待机/头部触摸/身体触摸/连续触摸/停止后的覆盖候选及坐标边界，并目视关键帧。保存独立可离线打开的HTML、动画与证据，不替代用户观感确认或设备FPS/触摸延迟测量。运行npm run check/npm test。
