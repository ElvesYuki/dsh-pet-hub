# 多 Wi-Fi 与动作候选日常换包

2026-11-20。用户授权将已验证的候选装入当前 DSH 桌面 profile。安装对象以归档摘要 `ede8a0dcffdd6965a4c154fd224be961ef7e77fef6b7ae239902dac6637a7650` 为准，包版本为 `0.0.8`。

## Spec

- 保留原桌面 profile、其他插件和 Hub 启用状态。备份原包、清单、锁文件及补丁。沿用已有运行路径、TCP 设置和动画来源选择。
- 根据[命名迁移记录](device-code-naming.md#新入口与日常部署边界)一次性替换 Hub 配置键。另建私有登记目录，保留原作用域后缀、USB 归属和加密 Keychain。macOS 允许新助手读回公钥，拒绝用原密钥签名。日常目录使用私有转接助手，只将当前既有引用的读取和签名交回系统已信任的原助手，健康检查沿同一入口。通过公钥摘要和签名核对身份，保留原目录作为签名入口及旧包回退。
- 使用实际 DSH CLI 和随包 loader 在独立临时 profile 演练。部署后在原桌面检查包来源、启用状态及设备设置入口。真机播放、配网写入和固件操作由统一联调安排。
- 原窗口的加载器若仍解析到换名前的入口，只在日常已安装包位置补一个转发文件，导出新版入口，并在同一窗口重新启用组件验证。仓库和归档继续使用正式入口，新启动的宿主通过清单使用正式入口。转发不接受旧配置键，回退时由旧包恢复原入口。

## Diff 与回退

变更范围为桌面 profile 的 Hub 依赖、该依赖的锁记录、Hub 的配置键及新登记目录。其它配置和插件文件按备份核对。切换失败时重装原 Hub tarball，恢复原补丁、清单与锁文件，并通过同一 DSH loader 确认旧入口。保留可用的旧登记目录和回退包。
