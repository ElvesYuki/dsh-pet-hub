# rc.5 桌面宠物设备单包 Spec

2026-11-19。rc.5 的实际加载器按 DSH peer 拒绝本机两个 rc.3 Hub 包。单包目标 `dsh-pet-hub` 保留原包名、设置槽和桌面副作用门禁。rc.5 组合包使用已安装宿主核对的精确 peer，提供管理查询、电池／传感器、USB 绑定、Wi-Fi 及天气地点。原 `dsh-pet` 独立提供任务状态。

- 新的主包配置包含 `vp8Enrollment.enabled` 与 `vp8Enrollment.enrollmentDirectory`，默认关闭。迁移仅将旧登记包同名字段折入主包，保留主包其余配置，将旧登记包从 profile bundle 及对应覆盖移除。原路径、绑定索引、Keychain 及 USB 设备关系原样使用。
- 共用原登记 owner 的进程槽、原 USB 排他和原查询 UDS owner。旧登记与新单包同时申请同一进程槽时拒绝重叠。卸载后等连接、串口和 UDS 退出，新实例拒绝旧请求。页面既有精确路由和回执复用；不修改固件或数据格式。
- 在临时 profile 验证真实 rc.5 加载、一份包一个设置槽、实际 Connection 授权及只读状态、重新挂载和释放。用合成设备身份与 Keychain 引用，无真机、旧 profile 更改或网络服务迁移。现场部署属于独立授权。

## 授权后的现场切换

用户授权安装单包并清理被替代的旧 Hub。先核对安装包摘要及实际 profile，私有备份安装清单、锁文件和配置。在临时副本预演 DSH 安装与配置迁移。现场只替换 Hub 主包，移除旧登记包及其专属条目，保留其他插件、原登记路径、Keychain 和固件。部署失败恢复备份，既有设备配置不参与回退。
