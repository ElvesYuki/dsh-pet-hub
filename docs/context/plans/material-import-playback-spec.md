# 素材导入与每设备播放装配 Spec（实现前）

2026-10-29，离线模拟切片。新增只读本地目录导入器：只由显式CLI参数提供目录、index.json原始字节SHA256、已审核license_ref白名单；不开放网页任意路径/URL读。取得服务所有权后导入，失败启动拒绝且不覆盖偏好。index上限256KiB/32变体，每文件8MiB、总32MiB；纯文件，不跟随根/子目录/文件符号链接，拒绝绝对/..路径、特殊文件及声明长度/摘要不符。逐文件流式有界读取；验证完成的字节快照保留内存、后续读取副本，不依赖变化的源文件。manifest摘要对去除路径的规范化元数据计算；index外部可信摘要独立校验。

本轮只解码微型合成SIM2（magic+宽高+动作ID+帧数+两个样本字节），不把它当PET4/真实RGB帧。导入器拒绝其它codec与不匹配头；真实PET4导入/解码另做。许可白名单由本机显式配置传入，目录自称授权无效；不复制上游动画。测试合成素材写临时目录。

新增纯core每设备播放协调器，依赖注入摘要/格式校验和读取，不依赖Node/DSH。每100ms虚拟步装配已保存选择与scheduler目标；300ms素材复验，400ms模拟首帧提交，accepted/verified/playing分开。每设备保存revision/会话/意图版本/动作组成目标代数，切包丢弃旧pending；失败/不兼容保留之前actual、显示失败且不回退包。断连取消pending并保留最后观测，重连重新装配；重启无播放恢复，只有偏好恢复。旧actor仍原S1四槽回归，新增material_playback字段独立表示SIM2实际装配，明确模拟非实物，不冒充Flash安装/硬件首帧。

导入支持多个角色（共享既有8动作语义ID），候选标角色/变体；UI保存后虚拟推进才进入导入素材模拟播放。内置元数据PET4候选保持metadata_only，不伪造可播放。导入快照仅存在本次服务；下次重启重新导入并核验摘要，旧偏好摘要不匹配unsupported。

测试：有效导入/头与摘要/长度/许可/路径/链接/数量大小拒绝、快照防篡改；A360/B240分配、动作来源/手动、切换中旧帧隔离、复验失败保留actual、断连重连/重启、默认disabled拒绝导入、附件启动配置一致性、IPC/UI白名单。回退仅停止临时服务与移除测试目录；现有配置和固件保持只读/不访问。
