# 本机任务来源 Spec 与 Diff

DSH 和 Codex 各有自己的只读适配器。pet 源码供对照状态分类，DSH 适配直接调用 rc.5 已带的 `sessionController.state({sessionId}, signal)`，无需运行 pet。应用选中会话由用户指定。首版状态快照区分运行、等待、空闲和不可用。快照没有成功完成证据时回到本地策略。既有 pet 候选保留为兼容来源，只有已配置公开地址的宿主可选。

Codex 通过显式配置且同用户拥有的本机 Unix socket 直接连接已运行的 App Server。使用官方文档的 Unix WebSocket transport，只发送 `initialize`、`initialized` 和 `thread/read` 的 `includeTurns:false` 查询。选择页不能设置地址或凭据。若未提供兼容 endpoint，Codex 显示未配置。此轮不启日常 daemon、不读 JSONL 历史，现有 Codex Desktop 会话是否共享其本地控制端点需另验。

## Diff

- 独立来源契约为 `read({signal})` 返回归一化状态，`close()` 回收独占资源。DSH 和 Codex 的归一化过滤只接收生命周期布尔值或枚举。轮询串行，每次读取受截止时间限制。读取可在圆屏断开时继续，VPC1 只消费同来源同会话的已观察边沿。
- rc.5 增加默认关闭的设置入口，在既有 Connection 认证域读写选择。UI 只显示来源、会话和状态。一次选一个来源，保存到既有私有 query 根下的单设备配置。保存校验当前 revision，先原子替换文件再切换内存。切换和关闭须阻止旧读结果提交，等待旧资源释放再启新读取。上一轮工作态不能在切换或重连后重放。
- 独立快照运行态现阶段映射动作 2，待机和等待沿用本地播放。原 pet 兼容路径维持角色 0 的 1／2／3 映射。DSH 工具细分、Codex 成功完成／首帧真机联调留给有可靠终态的下一阶段。

主机回归覆盖来源与设备解耦、关闭和切换、过期读取、并发版本、原配置迁移、输入负例及默认关闭。验证本机协议时使用合成会话和独立临时端点。回退关闭候选功能或恢复原包及其配置，保留日常 DSH、pet、Codex 和固件。
