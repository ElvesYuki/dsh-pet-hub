# VP8 BOOT USB 契约对拍 Spec

2026-11-17。驻留 VP8 `0.1.4` 没有绑定能力或绑定帧入口。只读核对固件 `ota_firmware.cpp` 的单一文本解析器，以及旧 native400 的 PBP1 `media_binding_wire.h`。复用已出现的字节及语义，标明 VP8 仍待确认的部分。

先用独立宿主编译引用固件真实 PBP1 和 VP8 文本行解析器。对拍旧类型 6／7／8、129／130／132，区分能力、等待实体按键和持久状态读回。用本仓库候选夹具对拍保留单一 USB 读主的 Base64 文本封装，检验半行、粘行、错长、CRC、错误方向、旧 reference 和无能力输入。任何拒绝的候选行不得将其载荷转给维护命令。

联合门禁要求固件明确确认新能力、线上封装，以及不发布 PMA1 租用也能验证的最终回执和可信未绑定语义。历史 PBP1 等待／Bound 状态均不能直接作为 VP8 绑定完成。候选封装通过宿主只说明可与当前行解析及旧帧搭配。只有联合门禁通过后增加管理端私有存储和设置页。

本片离线，测试使用合成向量，固件仓库仅只读，编译出物仅临时目录。现有 `STATUS2`、Desktop 免输入及部署路径保留。
