# 1.75C-EN DSH 一键 OTA 0.1.4 Spec

2026-11-16。复用独立 DSH rc.3、私有 Hub、同源授权、实例与 revision、单作业及 USB 独占。仅 `media2` 私有运行配置显式注入获批 release（版本、绝对文件、长度、SHA-256）才出现升级按钮。用 ESP 签名镜像头尾、≤2 MiB、实际字节数和固定摘要核对发布对象，设备负责用内置公钥验签。发布服务只响应本次 `GET /firmware.bin`。旧 MEDIA2、STATUS1／UPDATE1 和 PET4 入口保留。

升级前读 STATUS2，要求 `0.1.3`、空闲、未选待启动槽。macOS 用 USB registry 中当前明确串口对应的 Espressif VID/PID、USB 序号及物理位置绑定重连接，信息只留内存。Hub 不向设备指定槽位。一次 OTA2，核对本次 ACCEPTED 后的 SELECTED。收到后实际关闭发布端，再向同一个独占 TTY 发一次 REBOOT2；局部写入结果未知时也不重发。随后关闭旧 fd，在有界窗口重开同一 USB 并重新发 STATUS2。读到 0.1.4 且实际运行槽改变才显示成功。设备侧 STATUS2 服务在待确认新版本的自检通过后才启动。明确拒绝显示失败，断线、超时、旧版本或换设备保留未知语义。SELECTED 只用于推进自身作业，不充当成功，也不从旧版本推断回滚。

宿主先覆盖身份、顺序、错误和重复保护。真实 DSH rc.3 仅在固件 `ready.json` 的 `released=true` 后打开指定 USB。只点击一次正常版本升级，对比同一发布包的身份。结束关闭 HTTP、串口、浏览器及独立进程，删除临时私有资料，保存脱敏交接。故障镜像、OTA 回滚归因、离线存储／播放核对由固件任务负责。
