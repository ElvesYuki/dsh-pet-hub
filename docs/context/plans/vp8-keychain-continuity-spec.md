# VP8 绑定凭据长期保存 Spec

2026-11-17。只用独立合成 macOS 文件 Keychain。沿用原作用域、索引、P-256 私钥、keyRef、公钥及系统访问控制。只有索引处于 bound 且新进程实际签署随机挑战并验签成功，才认为活动目录可用。打开库或读到公钥只证明了读取。

## 路径与回退

- 将原签名助手逐字节保留，避免本地重编译改变 Keychain 识别的代码身份。原二进制可打开长期目录时，才允许将同作用域副本用作活动目录。
- 历史助手可能只允许临时路径。若不能在长期目录签名，先做长期私有恢复副本，恢复时只允许将该作用域放回原有临时路径。目标必须不存在，禁止覆盖。恢复副本不可作为活动根。
- 源目录保持可用。操作前停止该作用域的所有 owner 并确认释放，使用已有写锁保护复制窗口。只复制索引、原助手、受保护的库与解锁文件，以及已有明确 USB 选择文件。索引和字节做一致性核对，文件和目录同步。失败撤销本次创建的目标。现有配置只由操作员在独立现场窗口决定是否切换。
- 无交互签名仍执行原助手的 Keychain ACL。禁止导出私钥、更改 ACL、扩大授权、生成替代密钥或触发设备操作。若两种路径都无法签名，保留原作用域并停止迁移。任何系统原生交互式授权方案单独评审。

## 验收

合成 Keychain 对比原助手、内容不同的助手、不同目录下的原字节助手；单独模拟仅接受旧路径的助手。通过新进程验证原 keyRef、公钥和签名，记录系统拒绝的 OSStatus。验证失败清理、源仍能签名、恢复拒绝覆盖以及源目录丢失时的原路径恢复。现场不执行命令。
