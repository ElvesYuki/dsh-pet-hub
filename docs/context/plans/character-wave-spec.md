# 短挥手桌面原型 Spec/Diff

2026-10-30，用户确认抬手候选后授权继续。复用现有两种手臂图，无新增生成图；原母版/四态/46动作不覆盖，音频和真机仍延后。

## 设计

- 纯逻辑挥手通道：进入0.45秒，轻摆3次共1.5秒，退出0.45秒。肩部固定，末端小摆；使用原放下手臂与已制作抬手姿态，通过肩/腕两锚点等比旋转注册到共同姿态并混合，减少直接切图的双手分离。
- 混合在独立离屏画布以加法累积互补权重，再正常绘制；不直接在人物上连续source-over淡化两张臂，避免共有区域透明度下降。肘部形状沿用两张原姿态，不施加仿射剪切；过渡由两张姿态插值近似，不冒充已完成独立腕骨/隐藏面。
- 挥手期间基础态/触摸/眨眼/嘴型和头发照常推进；仅暂时拥有右臂。自然结束回到当时基础右臂。取消从当前抬手程度/摆角连续退回，重复start在活跃期拒绝、不排队；代数拒绝旧取消。
- 肩袖连接和过渡形变是本轮重点视觉风险；图层顺序为姿态候选局部前景，静止无挥手时沿用原绘制顺序。若仿射形变不可接受，另补中间姿态，不称最终成品。

## 交付验证

新增离线挥手开关/打断、场景回放与组合预览，保存动态演示和关键帧。纯逻辑测试时序、连续退出、重复/旧控制、有界输入及确定性；浏览器检查操作、肩部低覆盖/安全圆和中间帧观感。全身旧静态内区包含已移走的旧手臂，不将其全部当露洞；仅固定身体内区作为覆盖参考，并明确掩膜范围。运行check/test，记录实际结果；不改双时钟等无关实现。

实施修订：首轮三锚点仿射中间帧手掌明显拉长，已放弃。改为肩腕两点相似变换（旋转＋等比缩放），保持每张手部局部比例；中间帧仍需审视轮廓混合。
