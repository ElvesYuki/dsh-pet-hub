## 圆屏与设备卡电池图标 Spec／Diff

圆屏顶部弧线及 DSH 设备卡使用相同的视觉规则。电池内部填充对应百分比，低于 20% 用黄色，20% 保持常规色。接入 USB 时在图标内部绘制有深色描边的闪电，纯电池供电时隐藏。电量文字在图标右侧。闪电表示外部供电，充电中和已充满由设备卡文字补充。

| 模块 | Diff 与验收 |
| --- | --- |
| 固件 | 从现有 PMU 电池样本给 `DesktopStatus` 同步 USB 供电和电量，随原缓存过期，不增加采样。复用原弧形状态栏、像素范围与分条绘制。USB 已知有输入而百分比缺失时显示空电池及闪电。 |
| DSH | 用同一个电池图标取代百分比下方进度条。供电标签仍来自请求返回的 USB 供电字段。旧读数以灰色显示并保留提示，隐藏已过时的闪电。保留当前 TCP/USB 优先级与独立 USB 归属。 |
| 验收 | 覆盖 0%、19%、20%、100%、电量未知、USB 插拔和灰显。在宿主像素测试中核对满电、低电量时的闪电、圆形边界和分条绘制，对 Hub 做断线回退的原投影回归。固件签名、烧录及现用圆屏的实机动画表现另验。 |
| 日常换装 | DSH 测试通过后从现用包生成仅含电池视图的新版本，在同一窗口核对新图标和心跳。原包及配置保留供回退。 |
