## 变化

- 独立纯数学模块处理360共同坐标中的支点旋转、父子矩阵和确定性采样，不依赖DOM/DSH/设备；所有根变换保持单位矩阵，不缩放或重新居中。
- 检查11个可动发束各自±2°、头部±1.25°、全11束错相周期。发帽和头饰/耳鳍仅继承头部；末梢继承对应长发。单轴试摆不代表三维转头。
- 检查页可暂停、逐帧拖动、选择单部件、切换黑/浅底、显示支点与候选漏缝；目标采样24fps，仅为宿主制作参数，不是设备或面板实测帧率。
- 用冻结底稿向内侵蚀4px的密实覆盖区，寻找运动帧alpha<200的新低覆盖，输出候选坐标/数量；此指标用于定位，不能将正常轮廓变化计为确定的美术错误，也不能检测所有烘焙边色。
- 先测原母版，再按实际暴露的裁切/根部问题修订离线制作方案；修订必须新版本、静态回零检查并保留对照。不会自动抹去轮廓/画布边缘来伪造通过。
