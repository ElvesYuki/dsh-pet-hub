# 全部对话联动 Spec 与 Diff

## 范围与契约

「动画联动」保留关闭和指定对话，增加可选的「全部对话」。每次仍选一个状态来源。全部模式无需填写会话 ID，保存后恢复之前选择的模式。Codex 项目 Hook 只覆盖进入现有私有接收端、在已授权项目范围内产生有效事件的本地对话。单会话 App Server 和 pet 兼容来源保持原范围。

已只读核对随包 DSH rc.5 的 `sessionController.list({}, signal)`。它枚举当前 profile 可见的历史和实时会话，通过 `remoteAccess` 过滤。实时项的 `running` 来自 Agent 运行状态，未加载历史项为 `false`。每隔至少 3 秒读一次列表，按 `running` 筛选。复用现有逐会话 `state` / `events`，逐次读取最多 16 条活跃会话，沿用一次采样的 2 秒截止。超出范围、错误或超时将该轮报告为不可用，避免以部分结果驱动动作。短于列表发现间隔的任务可能未被观察到。没有提供 `list` 的宿主只显示指定模式。禁止再注册会话监听或调用 pet 写接口。

聚合优先级为工作、等待输入、思考、整理。单条对话结束时移出活跃状态，仍有工作时维持工作。同一聚合状态不会因成员或回合变化重发。圆屏沿用单段播放，片尾由本地策略接管。全部空闲时交回设备本地策略。完成和出错动画仍在指定模式判定，全部模式不发送单条会话的终态。只有观察到有效状态变化且认证 TCP 连续在线，现有 `Play` 才会发出。开关切换、重连和旧任务不补播，固件与 TCP 报文保持原契约。

## Diff、验收与回退

- UI 和原鉴权路由增加 `scope`，省略时沿用指定对话。状态响应发布允许全部模式的来源。私有选择文件继续用 schema 1 保存关闭和指定模式，全部模式使用 schema 2，空会话 ID。非法范围、未知来源、附加字段和旧 revision 拒绝。切换先排空旧 owner，再启动新 reader。
- Codex 保持单私有 Unix 端点，复用原有按会话和回合过滤。全部模式最多跟踪 32 条会话，拒绝超出容量的新增开工，保留已有活跃回合。已结束、超期及迟到事件仍受各自时限约束。项目 Hook 定义和字节格式沿用已信任的版本。
- 宿主回归验证两条对话交错、单条结束不打断其它工作、关闭及过期、冷启动与重连无补播、持久化、不可用来源、列表负例与设置页。用隔离 rc.5 验证读取、模式切换和卸载。真实 App 多聊及圆屏低亮度唤醒单列真机验收。
- 回退旧版本前先将范围切回「指定对话」或「关闭」，使保存文件回到旧版本可读结构，也可恢复安装前的私有选择文件备份。
