# VP8 设置页状态来源 Spec

2026-11-19 · 管理端宿主切片

设备端当前实测版本为 0.1.29。Wi-Fi、SNTP 和设备直连天气服务已有固件证据。VPC1 v1 的 24 B Ping/Pong 不含遥测字段，现有无线认证、认证后状态帧及 ESP 资源预算待联合确认。

- 在管理端定义经过认证的 TCP 适配器入口。适配器必须先验证本地绑定、设备身份、启动周期和报文完整性，按已匹配的本地 USB 登记身份选入同一个设备页。页内 HTTP 无选源写入口。状态载荷只包含固件版本、启动槽和可选电池、触摸与 IMU 观测。身份、地址、凭据和未知字段不进入页面。
- 成功接入后立即取样，按 3 秒间隔调度。每次只认当前连接最新探针的匹配答复，基于宿主单调时间计算新鲜度。最后一次匹配状态距现在满 6 秒即降级，满 9 秒关闭其状态会话。新连接替换、断开、撤销及插件退出立即废弃旧样本。认证和固定字节格式由正式适配器负责。普通 VPC1 Pong 只确认控制连接，沿用既有控制租约。
- 新鲜 TCP 状态优先。宿主阻止电池、传感器和自动 USB 识别读取，取消在途采样并拦截晚回。页面清除旧 USB 观测，展示网络快照。没有新鲜 TCP 时，检测原登记 TTY 的存在，连接后立即发起一次 STATUS2，随后按 5 秒节奏读电池和传感器，检测拔插后重新读取 STATUS2。状态 HTTP 只看宿主缓存与 TTY 存在性。USB 读取仍经现有独占与身份核对。
- 既有手动查询、绑定核对和 Wi-Fi 配置仍为显式 USB 操作。天气和时钟的 TCP 写入待后续固件契约。设置页卸载会终止 USB 请求。宿主卸载也会关闭该插件持有的状态会话。
- 验收覆盖隔离 TCP、虚拟时间、无设备、插拔、错误目标、同号重放、过期、撤销、旧连接晚回、USB 在途取消及版本兼容。回退到已部署 0.0.8 的原 USB 路径，保留私有配置与登记索引。
