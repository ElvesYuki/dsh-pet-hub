# 400 PET4 TCP 素材发送切片

2026-11-11。按终端共同交接并行开发。HTTPS 真机在 OPEN 资源准入结束，设备已恢复 2cc7060d。管理端以独立维护连接、单设备单作业、动作 1/11 为首轮范围。

- 可信本地调用者显式提供单笔维护用途决定。决定固定 compact78 原 manifest/index 摘要、V2 namespace、动作、设备 boot、基准根序号及目标代数。复用现有 compact78 元数据解析。每次从固定动作文件打开只读 fd，按单块预算预验文件 SHA，发送期间再次计算全 SHA 并检查 fd/路径指纹。
- 语义发送流程独立于编解码。HELLO 与本地决定一致才 BEGIN，READY 后依次发送 DATA。每块等 socket 写完成及累计 ACK 才读下一块。全长和 SHA 成立才 END。Saved 要求关联 job、END 已尝试、确切文件 SHA 与推进后的根和代数。单独记录 sent、confirmed 和 Saved。
- 明确取消只针对当前 job。已开始的写帧先结束，随后发 CANCEL；已有的 READY 或最后一块 ACK 可能迟到。提交后真实 Saved 优先。断线、超时或报文无效保守记录 Unknown。调用者可在原 boot、同一管理端内存作业上显式查询，重启后的目录只展示新事实。查询不发 BEGIN 或解除端侧写栅栏。
- 试验帧暂称 PTM1 v1，小端，payload 上限 4096 B，单块最多 4076 B 原文件数据，单块在途。编解码和字节向量供双方评审。适配器只接受回环 socket，由测试/可信调用者创建监听。boot、CRC、SHA 分别用于关联和完整性。LAN 写入前须共同确定会话认证及用途授权方式。
- 固定整会话截止，并对 socket 等待与取消做退出验证。测试原创 PET4，覆盖 1/11、错身份、分片/粘包、CRC/截断、背压、精确结束、取消及同 boot Unknown 查询。端侧保存由假设备模拟。既有 PTC1 和 review 权限保留原用途。
