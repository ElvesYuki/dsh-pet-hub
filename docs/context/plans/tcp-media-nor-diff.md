# PTM1 与终端保存器回环改动范围

- 增加 hub 宿主专用 C++ 测试端，编译时直接从显式指定的固件目录读取现有 codec、保存器、NOR fixture 和 LZ4。所有生成物仅在临时目录。固件仓库保持只读，不运行其脚本。
- 新增 opt-in Node 测试，复用实际维护发送入口、合成 400 PET4 和 V2 NOR 初始目录。普通 `npm test` 无固件路径时略过该项。显式指定路径时编译并运行全部互操作验收。
- 验收包括动作 1 和 11、暂存写入后的 ACK、提交前后 CANCEL、提交前拒绝额外 DATA、提交后的断线及同 boot QUERY。保留共享向量与原 Node 回归。
- 更新交接、证据和上下文。回退只需关闭测试端并移除显式测试选项，无协议改版、生产装配、权限或存储迁移。
