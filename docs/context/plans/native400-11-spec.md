## 交付与不变量

- 写明已实现、拟定、待验证，不把设计向量当运行期门禁。产出操作契约、逐模块Diff、威胁/失败矩阵、后续小切片及宿主验收向量。
- 复用400-08读验、400-09持久化和400-10选主/鉴权，不重复reader/事务/服务。来源只对应PC审阅，device_evidence=false/media_validation=not-performed，不能填设备actual/saved/库存。
- 两份独立批准仍由可信调用者提供，固定在prepare快照和选主身份；网页提交批准正文、checkbox、账本或自身hash不能产生批准。换批准须新服务/明确新目录，保旧历史。
- 来源选择由可信运行层显式传入私有路径，页面仅获单次受限引用。现有代码未核验选择时与任务打开时是同一文件；拟扩既有reader的内部expectedSource指纹检查，在打开后/首字节前校验，不能只在外层stat后再按路径打开。
- 操作控制器绑定服务实例、可信审阅会话、批准摘要、选择代数和uint64请求序列；单选择/单任务/无队列。针对job_id取消，去重在busy前检查，旧请求/旧取消不能影响新任务。当前owner.cancel无ID，必须由控制器在同一同步调用栈检查后调用。
- 授权期限须在提交/发布检查同步核时钟，不能只用timer abort；拟增加内部Boolean gate，已进入非抢占提交跨期限可留历史但禁止current，无硬退出承诺。
- 取消/关闭先失效、busy等真实I/O退出；断HTTP不取消共享任务；取消不是持久回滚，rename后未知冻结至可信宿主显式close/reopen，不提供网页自动修复/清锁。
- 当前宿主代理只提供prefix，没有本项目已验证的原生文件选择或受信页面身份接入。X-Pet-Hub/Origin/随机client_id不构成用户授权；首次实现仅内部临时控制器/原创fixture，DSH交互写入口保持待验。
