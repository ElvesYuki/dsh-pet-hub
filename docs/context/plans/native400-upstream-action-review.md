# dsh-pet 0.4.9 全素材复查与 400 补录

## Spec

以 dsh-pet `v0.4.9` 的 114 段内置 WebM 为全集，核对本机已安装素材字节和原 78 个名称。所有段按现有 `(124,-6,400,400)` 固定裁区及 466 圆屏扫描 alpha。重点审阅未收录段最坏裁切帧与中段构图，按独立动作、需要动作链、裁切过大决定用途。只重新审阅未收录项，既有 78 继续使用已冻结编号和身份。

用户指定的睡觉三段和吃白饭玩法五段全部登记来源与用途。严重出边的片段保留为源素材参考，如实标明缺口。适合当前固定裁切的动作生成 400×400、24fps 的 VP8/IVF 离线候选，保留动作原时长。入睡、睡眠循环、醒来分段登记，吃饭玩法不沿用桌面窗口移动规则。新增普通动作按本轮审核追加，编号从 78 起。旧 78 目录留作基线和回退，候选尚待实屏和激活核验。

## Diff

- 复用现有 alpha 审计和黑底裁切，加一条可复建的离线复查路径。
- 输出完整几何清单、补录 catalog、逐帧 VP8 验证和本机预览，媒体仅在忽略目录。
- 核对 IVF 帧时间、关键帧、尺寸及两个宿主解码器输出。保留现有固件、设备缓存及运行配置的工作边界。
