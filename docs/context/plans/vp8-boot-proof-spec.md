# VP8 BOOT 持久绑定回执 Spec

2026-11-17。以固件交接 `round-pet-vp8-boot-proof.md` 和 type 10／133 的候选字段布局为准。沿用纯文本 Base64 载体、VP8 能力 bit 2 与历史首绑命令，增加仅 VP8 可用的完成查询。管理端为每个请求产生独立非零 32 字节 nonce，不重用已经接收的应答。CRC 保护完整性。设备信任来自本次已核对的直连 USB，最终回执无需设备签名且不发布 PMA1 租用。

同 boot 首绑通过 `poll` 查询已受理的非零 reference。重连使用 `fence` 的 reference 0，设备先失效原待按键与挑战，再读持久状态。管理端每次核对当前 boot、设备、模式、nonce、reference 和状态。成功的 Bound 还要比对控制者、绑定 ID、代数和完整公钥 SHA-256。只将成功的 fence Unbound 转换成可清除待处理记录的证据。原 129／132、Waiting、非 OK 和 Fault 都不能改变本地绑定记录。

本片在宿主将匹配后的证据交给既有离线事务。先与固件真实 C++ 回执及固定向量对拍，覆盖旧事务和异常回复。未装配私有存储、设置页或设备入口，现有免输入查询继续使用原路径。
