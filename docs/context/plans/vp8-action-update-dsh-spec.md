# VP8 动作 1 独立 DSH 验证 Spec

2026-11-16。固件报告 `2026-11-16-vp8-power-cut.md` 已验证首个 4 KiB 写入后拔电、旧对象离线播放、试验区无提交标记，以及恢复 `56644ffd` 后临时插件宿主的真机查询与重复安装。此轮验证真实 DSH Web profile 与设置页。

- 使用新临时 DSH_HOME、专用 profile、loopback WebServer、独立 Hub runtime 和候选包本地副本。先核对应用版本、安装分区与配置 schema。禁用遥测、源状态和空闲时不需要的外部接入，不登录、不运行会话，不修改生产 profile。
- 开始时确认本地端口与服务所有权。真机只查询已保存对象，限固件任务已释放且 USB 枚举能独立区分的 1.75C-EN。只发 `STATUS1`，安装和取消按钮不执行。实际空库存写入保持 PTY，需固件任务另划无已保存对象的窗口。
- 浏览器使用实际设置槽。验证入口默认隐藏、显式装配出现、授权错误、查询结果、已保存时禁止安装、刷新或卸载。设备状态以 USB 回执为准。卸载后入口和 HTTP 路由撤销，独立 Hub 保持运行至主动退出。
- 退出关闭自有浏览器会话、独立 DSH 与 Hub，检查进程、socket、HTTP 与 profile 清理，不触碰其他监听和实例。故障时先停自有入口再释放资源。没有 Flash、NVS、Wi-Fi 或素材迁移。
