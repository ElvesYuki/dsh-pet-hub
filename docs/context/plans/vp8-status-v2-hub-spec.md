# VP8 Status v2 管理端迁移 Spec

固件线程定稿 Status v2，同一公共二进制状态适用于 USB STATUS3 和认证 VPL1。首轮为离线候选，日常 DSH 和板上旧固件保持原路径。已经构建的 Status v1 包作为独立回退保留。

- 公共解码器校验 6–68 B、版本、槽、完整记录长度、维护位、字段范围和缺省值。USB 校验规范 Base64 与当前 8 位 ID，TCP 先核对 MAC、计数、会话和 Ping，再解码公用载荷。VPL1 默认协商 2，能力不匹配进入仅控制。显式 v1 候选依旧可离线复核。
- 隔离 rc.5 的 vp8StatusV2 选择设备查询、页面 USB 回退及配网和天气的版本回查。一次 USB STATUS3 提供同轮版本、槽、维护标志及可选读数。状态 v2 路径不查询旧 STATUS2、BATTERY1 和 SENSORS1。忙或选择待重启应显示维护，缺省数据不沿用为当前确认。
- 桌面 CLI 保留旧模式并加入显式 v2 查询和挥手候选。素材及 OTA 私有装配支持分别声明升级前与重启后状态版本，保持下载、签名、串口独占、回读版本与槽的门禁。升级成功仍以同一设备重连后目标固件及槽确认。
- 验证固件共享向量、协议回环、截断、错 ID／非规范 Base64、正常与维护状态、6 秒回退、9 秒关闭、重连停 USB、升级后槽核对。只读固件仓库和向量。未执行实板、烧录、日常配置修改或安装。撤销隔离配置可运行原兼容模式，保留 v1 本机候选。
