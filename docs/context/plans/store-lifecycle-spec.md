# 仓库版本、配额与安全清理 Spec（实现前）

2026-10-29，仅独立simulation/streaming。先补Spec/Diff，不接设备、不改固件/pet/bridge/现有DSH配置。

每个成功版本新增私有version.json：schemaVersion、index_sha256、完整已校验manifest元数据；不存源路径/凭据。旧缓存无元数据或元数据无效时保守保护，不能猜测引用后删除。worker验证全部通过后才发布描述文件和版本。

生命周期管理器只操作本次私有runtime/material-store。异步扫描列出版本、孤儿staging/trash、逻辑文件字节数和保护原因；拒绝链接、特殊文件、错误权限、越界名字和超量条目，未知内容保守阻止清理。统计是逻辑文件字节，不是文件系统block占用。

保护集合：全部持久设备选择（含离线/未知设备）、模拟actual和desired/pending的manifest摘要、当前装配版本、活跃校验stage和配额预留。按manifest索引保护整个版本，trash保留同样引用判断；未发布且非活跃staging可显式清理。没有自动删除。

配额为整个store的逻辑字节+未落盘预留，默认1GiB、CLI --material-quota-bytes显式配置，当前范围1B–8GiB。导入worker先验证目录元数据并计算去重文件+version.json预计新增字节，向主线程申请准入；成功才允许复制。已有版本只预留缺失元数据的增量。配额不足后台失败，不删除旧数据/偏好。降低配额后允许列出/清理但不自动逐出；多版本/孤儿/暂存都计入。配额与attach配置一致性绑定，暂不做运行时配额修改UI。

GET /v1/materials/versions提供带revision的审阅列表；POST /v1/materials/cleanup只收service_instance_id、expected_revision、entry_ids。每次重扫/重算引用，过期revision或任何保护目标整批拒绝；清理期间拒绝设备选择/意图写入并串行化配额准入，避免检查后新增引用。删除采用先隔离rename到随机trash、再次核验树指纹再递归删，不跟随链接；失败尽量恢复，若留下trash下次仍按原manifest保护。无断电事务保证，崩溃后残留只显式清理。

插件同源代理及共享UI增加刷新列表/逐项清理按钮、字节/配额/保护原因；已选择/播放/校验中项目按钮禁用。没有选择解除/强制删除入口；用户必须先变更选择/结束引用或切换服务配置。默认disabled不读写仓库。

验收：版本描述重启可读、离线选择/旧actual/pending/当前版本/活跃stage保护；非引用旧版本/孤儿stage清理，revision冲突与混合批次原子拒绝；配额含已有/暂存/预留、去重预算与失败无发布；坏档/链接/特殊文件拒绝；并发选择与清理隔离；关停释放预留；IPC/代理/UI离线闭环。每次修改后check/test，报告未覆盖的恶意同用户并发与掉电/跨平台。

回退：停止本轮独立服务，可撤回新增代码和本轮专用测试目录。清理为显式不可恢复文件删除，仅允许已审阅无引用版本；测试只删除原创/临时样本。既有配置、固件和外部素材目录不访问/更改。
