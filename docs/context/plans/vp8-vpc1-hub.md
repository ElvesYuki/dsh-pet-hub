# VPC1 Hub 离线适配

## Spec

- 严格实现固件 24 B VPC1 帧。接收侧只保留一帧的分片缓冲，错误或半帧 EOF 关闭。模型只接收由上层指定的非零、单调会话号，旧连接回调全部失效。测试传输只接收本机 loopback socket。
- Hub 保存一个带单调时钟截止的最新目标。新会话只提交当前仍有效的目标及剩余有效期。每个会话用递增序号，待回执表有界。5 秒发一次心跳，匹配 Pong 在 5 秒内超时关闭。旧 Ping 的返回、重复回执和播放回执不能代替 Pong。
- 将发送、Accepted 和 Presented 分开。仅当前连接、匹配完整票据、仍有效的最新目标、且显示序号递增的 Presented 确认首帧。设备回执按请求匹配，允许先收到较新 Ping 的 Pong，再收到旧 Play 的终态。Missing、Expired、Cancelled 终止当前目标，Superseded、Duplicate 和断线由状态显式呈现。断开清除首帧事实。仍有效的持有目标可在新会话重新提交；这是状态同步，单次交互不得被接成长期目标。
- 鉴权方案单独审查。现有 Keychain 只证明控制者身份，设备侧身份、会话号分配与加密完整性还需确定。保留「桌面宠物设备」及既有 USB 维护入口。圆屏自己经 STA 同步时间与天气。

## Diff

- 新增纯 core 编解码、会话控制模型和 loopback socket 适配。没有生产监听器或插件装配。
- 通过合成时钟、真实 loopback 和固件仓库原 C++ 实现覆盖正常及失效路径。编译产物写入临时目录。
- 文档记录现有 USB 信任、无线认证建议、协议语义差值及真机门槛。旧 PTC1、配对、素材和 OTA 路径沿用现有入口。
