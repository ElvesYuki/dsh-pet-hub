当前状态：九部件透明图集首稿已生成并仅存本地缓存，未完成部件矩形/叠放验收。用户随后要求优先精确对齐与多视图规划，部件继续制作暂缓，见[校准报告](../../reports/2026-10-29-character-registration.md)。

2026-10-29，用户基本认可中性形象后授权继续。采用第一版候选作为工作底稿（不是替换现有360正式资源），使用内置imagegen逐部件制作透明图；不增加第三方依赖，不运行外部固件脚本。

## 范围

- 准备后发/尾巴、躯干裙装鞋、左右手臂、脸部底色、前发头饰、眼睛、眉毛、闭合嘴等独立部件。首稿允许共享一张透明图集，通过各自矩形引用形成独立可编辑层，不伪称已输出多张PNG。先正面静态，遮挡区域适量补画，分组按结果调整。
- 图集采用明确网格与顺序，源矩形和360目标矩形分别记录；打包布局不等于角色坐标，不把贴图格子的中心当角色中心。所有部件在统一360画布按明确目标位置重建，整体映射沿用底稿注册，不对角色重新取景。高分辨率源稿不直接当360发布资源。
- 使用本地HTML按固定图层顺序真实叠放，并提供逐层开关；不将完整角色PNG伪装成可编辑分层工程。不以AI再次生成的“合成图”冒充图层实际叠放结果。
- 本地.cache/layered-character下新版本目录保存图层、提示词、原尺寸/alpha检查和清单。素材许可沿用THIRD_PARTY，不进入Git/dist。
- 新图层未必像素对齐，需如实记录漏画、重复、位置偏移和边缘差异；实际支点/触摸区域仍待美术与宿主原型标定。首次静态首稿不实现动作、音频、口型、设备渲染或资源安装。

## 验收与回退

目视检查每层是否仅有目标部件、具备真实alpha，以及源坐标下尺寸位置是否合理。对照页逐层开关检查遮挡与原图差异，未完成浏览器验证时明确标注；后续精确位置与形象由用户确认，不称首稿即正式资产。

按现有360基准显式映射预览，不改变现有角色大小/位置。保留原候选与现有46动作，无固件/服务/插件操作。回退仅移除本切片新缓存或文档。文档同步并运行npm run check/npm test。
