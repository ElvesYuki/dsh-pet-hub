# PBP1 管理端 USB 配对

2026-11-11。沿用固件提出的 PBP1 头、定长报文、CRC 和 HMAC 指纹。管理端新增默认关闭的一次性编排器，通过调用方独占交付的二进制事务适配器验证流程。`INFO` 读取预选设备的 Empty 和 boot，`OFFER` 使用进程内随机 32 B PSK。只有匹配 Pending 且用户输入的屏幕指纹一致时才发一次 CONFIRM。终端从 HostConfirmed 经新一次屏幕长按进入 Active，管理端可用 INFO 补查丢失回执。

- 每个事务有超时，整个编排默认 60 s，单次只有一个在途请求。丢失回复仅补查 INFO。已验 Pending 在确认前失败时可尝试发送原作用域 CANCEL，无法确认终端状态时等待其断链或超时清理。确认后的不明结果不授予租用，不取消可能已激活的设备绑定。
- 只在匹配本轮 boot、device、proposal 和 HMAC 指纹的 Active、且 USB 已真实退出后发布 `{identity, boot, acquire}`。PMA1 仅允许同一 boot 使用此 RAM 租用。关闭撤销现有及未来获取，放弃本地密钥引用。原始密钥和 OFFER 副本在生命周期结束时尽力清零。重启或换绑不自动恢复。
- 验收使用模拟 USB 和合成数据，覆盖逐字节向量、两步确认、丢回执、错误/过期状态、互斥和资源退出。没有实际 USB 打开、配置修改、持久密钥或 LAN 写入。
