# PBP1 人工 BOOT 按键确认

2026-11-12。显式 `--pair --button` 选择直连、独占 USB 的人工验证流程。既有编排先校验预期 device、boot、Pending 提议和 HMAC 指纹，CLI 随后自动确认已核验的提议。操作者看到设备提示后在终端 15 秒窗口内新短按实体 BOOT 键。只有同作用域 Active 且 USB 退出才发布 RAM 租用。

15 秒从设备端提示算起，由固件负责。管理端复用原状态机和超时。PBP1 v1 无线级改动，CLI 不从报文探测设备支持哪种手势，按键模式只用于固件任务确认的候选。本轮只用模拟 USB 和 PTY。
