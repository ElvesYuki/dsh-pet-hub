## 发布与失败边界

在输出同级新私有临时目录直接组装包，先执行完整L1目录审计，再复核已读输入未变化。发布时用mkdir独占认领输出目录；先写包外回执，再将已验证临时包rename为output/package，rename是最后的可失败I/O。发布前失败只清理自己创建的stage/输出壳，已有输出/源目录不动；不自动覆盖或安装。

这是调用方拥有的稳定本地目录内的导出，不是敌对并发目录替换的OS沙箱。输出壳在最终rename前短暂存在，但没有可见半成品package；回执须与package同时存在才视为完成。不声明目录fsync、断电事务或生产角色激活。
