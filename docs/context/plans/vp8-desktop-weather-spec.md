# VP8 独立天气地点 Spec

2026-11-19。桌面宠物设备增加独立「天气地点」。明确提交搜索时，由 DSH 本地 Connection 的认证路由向 Open-Meteo Geocoding 发出查询。搜索无需设备、串口或 Keychain。结果显示地点名、行政区、国家或地区和坐标。用户选中结果后显式保存，界面区分搜索中、空结果、失败和设备回执。来源为 Open-Meteo 和 GeoNames。

- 搜索走固定 HTTPS 端点 `geocoding-api.open-meteo.com/v1/search`，查询 2–80 字符、`language=zh`、至多 12 笔。不携 DSH Cookie、设备标识、已有配置或坐标。拒绝重定向，限制响应为 128 KiB 和 5 秒，宿主最多 4 个在途查询。页面关闭、重新搜索或宿主卸载时取消请求，迟到结果不能覆盖最新搜索。
- 设备 INFO/SET/CLEAR 使用独立路由。进入现有绑定 owner 的同一独占 USB 会话，复用 Type 6／10、Keychain 公钥及 revision 核对。SET 只接收 WGS84 万分之一度整数坐标。确认回执必须匹配请求 ID、操作和 SET 坐标。地点名称仅用于当前页面选择，设备回读显示实际经纬度。
- 写前只读探测 DESKWEATHER1，旧固件可同会话 STATUS2 读取版本，写入无降级。保存/清除超时结果未知，要求手动 INFO 复核，绝不自动重发。保存表示设备的持久回执，天气联网状态独立。清除独立地点会屏蔽 Wi-Fi 中的旧位置，设备实现该持久语义。
- Wi-Fi、NTP 和旧天气兼容输入沿用 DESKNET2，原查询、绑定、传感器和电池复用当前 USB 串行化。测试使用合成地点和设备。运行语法检查、全量测试并打包；实际设置窗口、外部请求和真机另验。
