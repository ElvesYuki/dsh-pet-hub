## 重新生成参考包

从仓库根目录运行，显式提供自己的只读360素材目录，不运行外部仓库的导入脚本。输出目录必须是本仓库.cache内尚不存在的新目录，避免覆盖已有制作资料：

```sh
node scripts/prepare-character-reference.mjs \
  --source-dir '<只读原生360素材目录>' \
  --manifest-sha256 a6a2ddae50a8fe4ddf15ff07a3a228dccf865bb91a037693ce0a72232204c39e \
  --license-ref dsh-pet-nc-86181ce \
  --output .cache/layered-character/p0-reference
```

该摘要只对应当前已审核源manifest；来源变化须重新核验，不直接替换摘要绕过审核。工具同步执行，无网络/服务/设备操作，成功后输出index.html、reference.json和25张PNG；输入校验失败不发布目录，写文件阶段I/O失败会报错，目录不构成可原子激活的角色包。HTML可用本地浏览器打开，原生尺寸是逻辑像素，屏幕缩放和浏览器缩放不等于实物毫米尺寸。

## 怎么拆图

先完成正面静态注册，再继续拆层。目前固定参考边界为[70,50,281,315]，人物外接框中心(175.5,182.5)不等于画布中心(180,180)，禁止额外自动居中。scripts/character-registration.mjs用单一等比映射计算位置，默认每条外框边误差≤0.5参考像素；超限拒绝，不能非等比拉伸。当前第一版草稿的外框计算误差约0.0133px，不代表五官、内部比例或全部轮廓逐像素一致；这些仍须叠加确认。注册SVG是完整栅格的坐标包装，不是发布PNG或已拆层工程。

第一张图只做正面中性待机。分层图重新合成，应先与当前待机吻合，再画其他表情和动作。

| 建议部件 | 建议父级 | 交付要求 |
| --- | --- | --- |
| body | root | 躯干和基础衣服，补全被手臂/头发遮挡的区域 |
| head | body | 脸部底色，不烘焙眼眉嘴；脖子连接处留余量 |
| hair_cap / fringe_* / side_* / back_* / ahoge | head或对应长发 | 按下节拆为12个发束/结构层，不再只分整片前发和后发 |
| head_accessories | head | 头箍、蝴蝶结和耳鳍保持身份细节，默认随头，不随发梢乱摆 |
| arm_left/right | body | 这里left/right统一指观众看到的画面左右；肩部重叠，抬手另补姿态 |
| eyes | head | 睁眼、半闭、闭眼、笑眼；瞳孔跟随需另拆可移动部件，首版非必需 |
| brows | head | 中性、开心、生气、疑惑，配合眼睛位置 |
| mouth | head | closed、small、wide、round、smile；额外嘴型以后补 |
| tail | body | 保留形象细节；与身体遮挡按实际参考决定 |
| effects | root | 心、汗、气泡分别制作，不烘焙进脸或身体 |

这是拆层建议，不是硬性12张贴图上限。画图时先保留同画布位置；导出裁掉透明空白后，记录原画布偏移，禁止把所有小贴图重新居中。正常alpha混合，避免依赖编辑器专用混合模式；边缘须在黑底和浅底检查有无白边/黑边。

性能测量放到完整视觉效果原型之后，记录可见/动态层数、透明重叠像素、旋转/合成耗时及内存。优先优化贴图缓存、变换计算和局部重绘；当前不通过减少动态发束、合并头发或缩小人物来预先降级。若后续实测确需牺牲观感，列出差异再与用户确定；实际24FPS和即时反馈仍未实测。

## 支点与清单怎么填

使用[空白制作清单](character-authoring-template.json)。它是美术交付表，不是runtime已支持的包格式。

- rest_origin_canvas_px：未动画时，裁剪图左上角在360画布的位置。
- pivot_canvas_px：未动画时，支点在360画布的位置；手臂在肩，头在颈部附近，由美术标定。
- 对应贴图局部支点为pivot_canvas_px减rest_origin_canvas_px；角度以屏幕坐标顺时针为正，单位度。
- source是相对素材目录的路径；width/height是裁剪后的实际像素尺寸。空值表示尚未测定，不允许在正式导出时默认为0。
- parent只是层级，不决定前后遮挡；z单独标定。静态叠放建议先按后发/尾巴/身体/手臂/脸/五官/前发试排，再按参考纠正。
- 触摸区域使用360坐标多边形，待样本完成后标注；眼睛、嘴巴、手臂的纹理边界不能自动等同触摸范围。后续触摸需逆变换到对应角色部件。

## 最小动作与表情约定

| 样本 | 首版制作目标 | 暂定约束 |
| --- | --- | --- |
| neutral | 合成静态待机，与参考对齐 | root不做额外居中/缩放补偿 |

五嘴型和无音频控制已有桌面候选，不预先宣称发音精确。2026-10-29用户决定将真实音频播放/音量开合/时间戳同步延后到真机阶段，当前保留已有素材与无音频预览；恢复条件见[整体规划第4节](../context/plans/layered-character-plan.md#4-对话与口型)。后续仍以实际播放进度为主时钟，虚拟演示与语音同步分开验收。

## 给绘图/辅助工具的制作任务

“按提供的当前角色参考，制作同一角色的正面中性分层待机图。保持脸型、头身比例、服装、发型、头饰、尾巴、配色和当前360画布中的大小位置；不重新设计、不自动放大居中。头脸底色与眼眉嘴分开，补画遮挡区域和关节重叠。每个部件保留透明背景和原位置。先交静态合成图与图层清单，不制作整套动作。”

这段是可编辑制作说明，不会自动调用图片服务。独立生成部件很容易风格漂移，应先确认整张角色，再局部拆分补画。参考素材的二创仍需遵循原许可。

## 多视图与姿态库

| 顺序 | 视图 | 用途 |
| --- | --- | --- |
| 1 | 正面中性 | 当前大小/位置基准，呼吸、眨眼、表情和嘴型 |
| 2 | 朝画面左/右的四分之三视图 | 小幅转头、侧看、思考，补近远眼和脸部遮挡 |
| 3 | 朝画面左/右的侧面 | 明显侧身、转向；重新绘制眼口、耳鳍和发型轮廓 |
| 4 | 背面及必要的侧后视图 | 完整转身、背向动作；按需要再扩充 |

不是所有功能都需等完整转身模型：首个呼吸/眨眼/说话原型只用正面。各视图有自己的姿态贴图/部件和嘴型，不把正面平面图大角度旋转当作转身，也不强求左右镜像（头饰、尾巴和服装可能不对称）。

视图共享角色原点、统一尺度与头身关系；脚底接触线和骨骼连接位置按动作语义确定，不用各自包围盒自动居中/铺满。先保持体积一致，再处理转头时合理的可见宽度变化，不把透视变窄强拉回正面宽度。

现有动作39“小幅度原地360度旋转展示”可作视图来源。本地turn-reference-v1已采样9帧，frame60/90目视可见侧后/背向内容；这些是既有动画的姿态参考，不是已验证的正交设定图，源视频中的形变与服饰变化需与作者设定交叉核对。后续新视图先基于这些参考补画，不能凭空改变背面服装或尾巴连接方式。
