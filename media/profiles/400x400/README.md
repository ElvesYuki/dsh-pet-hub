# 400×400 圆屏素材规格

1.75C-EN 产品构建选择此规格，466×466 物理屏按原像素偏移 `(33, 33)` 居中。日常固件播放已有缓存的 VP8／IVF。源素材按 24 FPS 时间基准组织，具体帧数按素材清单核对，板上可持续播放速率见实机报告。

`playback.cmake` 提供固件画布边长。新增设备规格在 `media/profiles/` 增加目录，由板级入口选择。原 360×360 的素材身份、验证和回退记录继续保留。 [400 素材复查](../../../docs/reports/2026-11-18-native400-upstream-action-review.md) · [360 回退入口](../../../docs/context/plans/native360-baseline-spec.md)

日常固件构建无需私有素材。 `tools/` 提供原离线导出与诊断输入生成，必须提供相应冻结清单和批准的外部文件。尺寸和摘要属于素材身份，审批过的素材仅在私有目录使用。 [来源与素材许可](SOURCE_LICENSE.md)
